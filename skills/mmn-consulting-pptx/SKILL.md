# MMN Consulting PPTX

Use this skill as the MMN PPT Agent workflow. Treat MiniMax-AI/skills `pptx-generator` as the closest reference template: requirements, outline, visual system, slide generation, compilation, QA, and delivery. Adapt it for MMN by prioritizing editable PPTX, automotive marketing strategy narrative, reusable source code, and strict validation over decorative image-only slides.

## Product Boundary

- Keep all visible wording in MMN's domain: brand marketing, content strategy, campaign intelligence, creator distillation, content brief, script production, executive IP distillation, market weekly reports, and strategy reports.
- Do not introduce dealer-sales, showroom reception, sales-consultant, store handoff, or sales-script language into MMN decks.
- When model output is involved, use MMN-facing labels such as `MMN多模态策略输出` or `MMN模型输出策略`; keep raw provider names as internal QA detail.

## Engine Roles

- Use PptxGenJS as the main `.pptx` generation engine. Core elements should remain editable in PowerPoint: text, shapes, tables, charts, connectors, and native chart data.
- Use MarkItDown to parse Word, PowerPoint, PDF, Excel, CSV, HTML, and related source materials into Markdown. It is an ingestion layer, not a layout engine.
- Use python-pptx only for reading, extracting, inspecting, and light post-processing existing PPTX files. It is not the primary deck generator.
- Use Marp CLI to create structure-only draft decks from Markdown for storyline review. Marp output is an intermediate artifact.
- Use Mermaid CLI to render process, logic, funnel, or decision diagrams. Keep `.mmd` source so every diagram is reproducible.
- Keep page-structure JSON as the source of truth for slide intent, layout boxes, title hierarchy, chart metadata, page numbers, table-of-contents targets, and validation hints.

## Workflow

1. Ingest source materials with `scripts/mmn_ppt_ingest_sources.py`; preserve source names, page references, tables, quoted claims, and low-confidence extraction notes.
2. Build a consulting storyline: cover, table of contents, executive summary, logic/funnel page, evidence pages, opportunity diagnosis, recommendations, action roadmap, appendix.
3. Draft structure with Marp when fast title/order review is useful; do not treat Marp as final delivery.
4. Render Mermaid diagrams for logic trees, process maps, content funnels, platform action loops, or campaign intelligence flows.
5. Generate final PPTX with PptxGenJS from page-structure JSON; track every element with `id`, `role`, `x`, `y`, `w`, `h`, text, font size, color, and semantic level.
6. Validate before delivery. Required checks: Chinese overflow, element overlap, title hierarchy, chart readability, brand palette usage, page-number sequence, table-of-contents targets, and PPTX slide count.
7. Export PNG previews for fast review. Previews are QA artifacts only; final delivery remains editable PPTX.

## Project Commands

Use these from the MMN repo root:

```bash
pnpm install
python3 -m pip install -r requirements-ppt-agent.txt
bash scripts/run_mmn_ppt_agent.sh
```

Useful individual commands:

```bash
python3 scripts/mmn_ppt_ingest_sources.py source.docx source.pdf --outdir output/ppt-agent/markdown
pnpm ppt:generate
pnpm ppt:preview
pnpm ppt:validate
pnpm ppt:marp
pnpm ppt:mermaid
python3 scripts/mmn_ppt_inspect.py output/ppt-agent/mmn-strategy-deck.pptx --out output/ppt-agent/pptx-inspection.json
```

## Output Contract

- `output/ppt-agent/mmn-strategy-deck.pptx`: editable final PowerPoint generated by PptxGenJS.
- `output/ppt-agent/page-structure.generated.json`: slide structure, layout metadata, validation source of truth.
- `output/ppt-agent/generated-source.generate_deck.mjs`: generation source copied for traceability.
- `output/ppt-agent/previews/*.png`: slide preview images.
- `output/ppt-agent/validation-report.json`: machine-readable QA report.
- Optional: Marp structure deck, Mermaid `.mmd` source and rendered diagrams, Markdown source extraction manifest.

## Quality Bar

- Titles must read as an executive storyline when scanned alone.
- Chinese text must be sized conservatively; do not rely on auto-fit to hide poor layout.
- Charts must have readable labels, units, and source notes when applicable.
- TOC entries must point to existing slide IDs and match section order.
- Page numbers must be present, sequential, and unobtrusive.
- Brand colors must come from the MMN deck palette unless an exception is documented.
- Avoid image-only slides unless the source screenshot is the evidence itself.
