## 2. 推荐导入字段

| 字段 | 用途 |
|---|---|
| doc_id | 唯一知识块ID |
| domain | 一级知识域 |
| module | 二级模块 |
| topic | 具体问题或知识点 |
| entity | 车型、品牌、工具、方法论或对象 |
| knowledge_type | principle / framework / diagnosis / recommendation / instruction / rule / case 等 |
| content | 可向量化主体文本 |
| tags | 检索标签 |
| confidence | 置信度：high / medium |
| source_context | 来源类型：conversation_memory / uploaded_files / mixed |
| retrieval_queries | 建议召回问法 |
| status | usable / draft / needs_verification |

## 3. 建议切分与索引策略

- `content` 直接用于 embedding。
- `domain + module + topic + entity + tags` 作为 metadata。
- 召回时优先用 metadata filter 缩小范围，再用向量相似度排序。
- 不建议把整份PPT或长报告直接扔进向量库。原因：会召回泛摘要，不能支撑车型级策略问答。
- 每条记录保持“一个chunk解决一个问题”。后续补充数据时应继续遵守此粒度。
