## 汽车营销方法论

### MMN-AUTO-0001｜MMN总纲｜BAS-MMN定位

- **对象**：MMN / 上海艾姆恩信息科技有限公司
- **类型**：principle
- **置信度**：high
- **标签**：MMN、BAS-MMN、汽车营销基建、全域增长、定位

MMN应被定义为汽车行业营销基建型机构，而不是传统达人经纪MCN。核心能力是“策略洞察 + 内容生产 + 达人整合 + 平台投放 + AI数据复盘”的全链路增长系统。对外表达要压住“全域增长操盘机构”这一定义，避免被客户理解成单纯资源贩卖或达人撮合。

**建议召回问法**：MMN是什么；BAS-MMN定位；汽车营销基建机构

### MMN-AUTO-0002｜MMN总纲｜BAS-MMN路径

- **对象**：BAS-MMN
- **类型**：framework
- **置信度**：high
- **标签**：BAS-MMN、闭环、行业洞察、品牌策略、KOC、转化

BAS-MMN的作战路径是：行业洞察 → 品牌策略 → KOC内容 → 转化闭环。它服务的不是“做一波曝光”，而是把人群、内容、线索、试驾、订单、口碑复盘连成经营闭环。任何方案不得只讲传播动作，必须说明如何被销售/门店/私域承接。

**建议召回问法**：BAS-MMN路径；行业洞察品牌策略KOC转化闭环

### MMN-AUTO-0003｜MMN总纲｜五位一体服务矩阵

- **对象**：MMN
- **类型**：framework
- **置信度**：high
- **标签**：策略咨询、内容生产、资源整合、营销投放、AI Agent

MMN五位一体能力包括：策略咨询、内容生产、资源整合、营销投放、AI Agent复盘。策略咨询解决卖给谁、为什么买；内容生产解决用户语言翻译；资源整合解决KOL/KOC/KOS/媒体组合；营销投放解决效率优化；AI Agent复盘解决数据沉淀与下一轮策略迭代。

**建议召回问法**：MMN五位一体；策略洞察内容生产达人整合平台投放AI复盘

### MMN-AUTO-0004｜组织边界｜营销/转化/销售三线分离

- **对象**：汽车营销闭环
- **类型**：principle
- **置信度**：high
- **标签**：营销、转化、销售、三线分离、KPI

营销、转化、销售必须联动，但不能混为一个部门动作。营销解决认知与心智；转化解决用户从兴趣到试驾/留资/到店的链路；销售解决报价、金融、成交和交付。错误做法是用曝光KPI替代销售结果，或让内容直接背所有成交责任。

**建议召回问法**：营销转化销售三线分离；汽车营销闭环

### MMN-AUTO-0005｜品牌/车型DNA｜品牌DNA=人群，车型DNA=人群

- **对象**：品牌DNA / 车型DNA
- **类型**：principle
- **置信度**：high
- **标签**：品牌DNA、车型DNA、人群、用户画像、定位

品牌DNA和车型DNA都必须回到人群。品牌DNA不是品牌口号，而是品牌在什么人群中稳定成立；车型DNA不是配置表，而是这台车能在什么人群、什么场景、什么竞品替代关系中形成购买理由。所有车型传播先问“谁会买”，再问“讲什么卖点”。

**建议召回问法**：品牌DNA等于人群；车型DNA等于人群

### MMN-AUTO-0006｜内容原则｜技术用户化翻译

- **对象**：车型传播
- **类型**：principle
- **置信度**：high
- **标签**：技术翻译、用户利益、车型传播、心智标签

汽车技术传播必须从“参数展示”转成“用户问题解决”。例如底盘、三电、智驾、安全、供应链优势，都要翻译成好开、省心、安全、智能、家庭可用、长期成本更低等用户可感知利益。只堆技术名词，会导致用户记住企业很强，但记不住哪台车值得买。

**建议召回问法**：技术怎么翻译成用户语言；汽车技术传播

### MMN-AUTO-0012｜GTM+IPMS｜问题归因规则

- **置信度**：high

## 数据与RAG系统

### MMN-AUTO-0013｜MMN用户感知引擎｜四步主流程

- **对象**：MMN Perception Engine
- **类型**：framework
- **置信度**：high
- **标签**：MMN用户感知引擎、NSR、Emotion、Attribute、Identity、Positioning、Gap、Action

MMN用户感知引擎的主流程应固定为：NSR → Emotion → Attribute → Identity → Positioning，并在后续加入Gap与Action。核心原则是每次分析必须以一台本品为中心，通过竞品分析确定本品下一阶段营销重点，不能变成泛行业舆情分析。

**建议召回问法**：MMN用户感知引擎流程；NSR Emotion Attribute Identity Positioning

### MMN-AUTO-0014｜MMN用户感知引擎｜NSR定义

- **对象**：NSR
- **类型**：definition
- **置信度**：medium
- **标签**：NSR、净情感、舆情、属性拆解

NSR用于判断某车型或某传播点在用户评论/舆情中的净正向程度。它不能单独作为结论，只是情绪层的入口指标。NSR之后必须继续拆Attribute，看正负向到底集中在外观、价格、续航、智驾、空间、底盘、品牌、服务还是竞品替代关系。

**建议召回问法**：NSR是什么；净情感值汽车营销

### MMN-AUTO-0015｜MMN用户感知引擎｜Gap与Action

- **对象**：Gap / Action
- **类型**：framework
- **置信度**：high
- **标签**：Gap、Action、Gap Size、传播机会、认知空位

Gap用于识别本品传播与用户真实关注之间的错位，Action用于把错位转成下一阶段传播动作。Gap必须评估Gap Size，即问题规模、影响人群、与成交链路的距离。小Gap适合内容微调，大Gap需要重构人群定位、价格话术、竞品打法或KOC证词体系。

**建议召回问法**：Gap Size怎么定义；传播机会和认知空位

### MMN-AUTO-0016｜指标体系｜BVI/TVI/SEI/RWI

- **对象**：周度流量周报
- **类型**：framework
- **置信度**：high
- **标签**：BVI、TVI、SEI、RWI、Action、周报

周度营销流量周报应拆成BVI品牌声量、TVI车型声量、SEI策略效率、RWI风险预警和Action动作闭环。公开数据只能证明相对热度，不能直接证明经营结果；周报价值在于判断声量是否沉淀到车型心智、试驾线索和门店动作。

**建议召回问法**：BVI TVI SEI RWI；周度营销流量周报指标

### MMN-AUTO-0017｜数据采集｜全渠道数据源

- **对象**：抖音/小红书/懂车帝/汽车之家/微博/B站/私域

数据采集应覆盖短视频、垂媒、社交、论坛、私域和线下转化。短视频负责破题与即时声量，懂车帝/汽车之家负责同价位比较和参数权益承接，小红书负责家庭/女性/通勤/露营生活方式种草，B站负责技术长视频和深度解析，微信/私域负责试驾与订单承接。

- **标签**：上汽集团、尖锐标签、车型心智、主战车型

- **标签**：上汽智电底座、集团叙事、车型承接

上汽体系的真实优势在于长期工业积累、零部件体系、合资与自主经验、三电和底盘集成能力。但营销上不能只说“集团供应链强”，应翻译成用户感知：车身安全、底盘成熟、制造一致性、服务体系、长期可靠性、关键部件匹配效率。
