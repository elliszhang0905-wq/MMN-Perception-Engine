# MMN 周度刷新双环境发布计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将已验收周度刷新修复提交、部署至受管本机与服务器，并启用相应周度调度。

**Architecture:** 从各自运行基线增量整合；本机通过既有受管发布器生成不可变包并切换，周度 LaunchAgent 仅调用回环 API；服务器复用现有镜像依赖层，仅叠加本单运行文件，沿用仅代码蓝绿部署，最后定向重建调度器。

**Tech Stack:** Python/Bash、launchd、Git、Docker Compose。

## Global Constraints

- 用户已授权本单提交、部署与启用；不启用品牌复核或其他独立功能，不改变其他后台镜像。
- 不覆盖 `.env`、Compose、数据库、数据卷或原运行中的独立增量；版本元数据除外。
- 配置/数据备份保持私有，禁止输出环境秘密；旧镜像和物理 release 保留可回退。

## Rollback

本机沿用发布器与 agent 的事务回退入口，卸载本单 LaunchAgent 以停止新增触发；服务器从保留旧镜像恢复应用和调度器，并核验代理健康。普通回退只回退代码/任务配置，保留合法新增数据。若任务活跃、持久化检查异常或回退身份不明确，则不做切换，先定位风险。
