# beta 1.02 系统级迭代发布

日期：2026-07-12
版本：`beta 1.02`
版本码：`beta-1.02-system-iteration-1`

## 版本定义

2026-07-11 至 2026-07-12 的连续开发成果统一定义为一次系统级迭代，不按页面微调或单点修复拆分发布。实际客户是汽车品牌市场营销负责人，系统主链路为：

`真实 NSR → 垂媒竞品关系 → 机会判断 → 产品事实补证 → 策略动作 → Learning / Know-how 回流`

社媒证据用于补充用户语言、争议强度和竞品占位，不被解释为市场全量需求或成交证明。

## 主要迭代

1. 以奥迪 E7X 真实产品评价与汽车之家周度关系数据重构决策驾驶舱。
2. 增加属性级本品/竞品气泡、三平台对照、双车完整周趋势及明确时间范围。
3. 将 NSR、垂媒关系、产品事实缺口、人工策略选择和 Learning / Know-how 串成可追溯闭环。
4. 隐去重复且容易造成自动决策误解的“NSR × 垂媒合并判断”展示层。
5. 修复缺失/真实 0、整体/属性 NSR 串读、重复解析、Excel 日期、富文本、社媒助手字段和小红书达人字段等全局读取问题。
6. 将垂媒资产、机会地图任务、文档、复核、执行周期、策略资产和浏览器缓存按客户空间、版本及车型隔离。
7. 补齐社媒趋势、达人蒸馏、品牌传播穿透和 Auto Consulting OS 方法论基础。
