# 达人能力资产系统V1研发记录

## 研发日期
2026-07-05

## 版本号
v1.0-beta 1.01

## 需求背景
内容能力蒸馏库原有页面以内容片段和 RAG 卡片为主要呈现方式，用户导入社媒助手文件后难以直接判断系统沉淀出了哪些可调用能力，也无法直接服务新账号孵化、咨询业务选达人和达人库资产进化。系统需要从“内容片段管理”升级为“达人能力资产管理”。

## 问题分析
1. 社媒助手导出文件存在“达人UID”和“达人昵称”等字段，旧规则容易把数字 UID 识别为账号名。
2. 部分导出文件没有独立标题字段，旧规则会把文件名作为内容标题，导致页面展示不专业。
3. 原卡片直接展示 RAG 片段，缺少账号级能力画像和业务调用入口。
4. 用户无法从当前页面直接拿到账号定位、内容母题、选题公式、脚本结构、语言风格和适配任务。

## 技术方案
1. 优化通用文件导入字段识别规则，优先识别“达人昵称、博主昵称、用户昵称、账号昵称”等字段。
2. 当标题缺失时，使用视频描述或口播文案生成可读标题。
3. 新增达人DNA资产包聚合逻辑，按平台与账号聚合同一达人样本。
4. 每个达人资产包输出账号定位、内容母题、选题公式、脚本结构、语言风格、可迁移边界、适配任务和推荐调用场景。
5. 前端页面新增六个业务调用入口：用TA孵化新账号、按TA风格生成脚本、生成30天选题日历、生成客户达人brief、查找相似风格达人、加入MMN达人库资产。
6. RAG片段降级为辅助证据区，不再作为主交付物。

## 功能实现
- 修复社媒助手抖音导出文件中账号名被识别为数字UID的问题。
- 修复文件名被误当作内容标题的问题。
- 支持达人级 DNA 资产包生成。
- 支持达人能力资产卡片展示。
- 支持六类业务调用入口的前端交互反馈。
- 保留 RAG 片段作为可追溯证据。
- 清理并重新导入“猴哥说车”错误样本，生成正确账号资产。
