# 云端登录页与管理员试用者权限体系

## 研发日期

2026-06-27

## 版本号

v1.2.5

## 需求背景

MMN Perception Engine 当前已经具备本地开发环境和阿里云 ECS 云端演示环境。为了让云端演示更接近产品化使用，需要在服务器版本增加登录页和基础权限体系，同时保持本地 Mac 免登录、直接进入工作台的工作方式。

## 问题分析

当前系统在本地开发阶段强调快速迭代，但云端演示环境面向客户或试用者时，需要具备最基本的访问边界：

1. 管理员需要完整管理权限。
2. 试用者只能体验核心演示能力。
3. 本地开发不应被登录流程打断。
4. 登录页需要符合 MMN 高级灰、碳黑与品牌视觉体系。
5. 云端 API 需要配合前端做基础权限校验，避免试用者误改云端数据。

## 技术方案

1. 增加云端登录开关 `MMN_CLOUD_LOGIN_REQUIRED`。
2. 本地默认不启用登录开关，保持免登录。
3. 云端通过 `.env` 配置管理员和试用者账号。
4. 后端登录成功后签发短期访问令牌。
5. 前端请求自动携带访问令牌。
6. 试用者前端禁用导入、清空、同步、写入类按钮。
7. 后端对云端写入类接口增加管理员权限校验。
8. 登录页使用 MMN 品牌背景图和淡灰色交互框。

## 功能实现

1. 新增云端登录页结构。
2. 新增登录页视觉样式。
3. 新增后端云端登录配置、账号校验、访问令牌和权限校验。
4. 更新前端 API 请求，支持自动携带登录令牌。
5. 更新云端测试脚本，支持先登录再执行模型能力测试。
6. 更新 Docker Compose 环境变量配置。
7. 更新部署文档中的云端登录与权限说明。

## 测试结果

已完成：

1. 本地免登录验证通过，本地默认直接进入工作台。
2. 本地发布门禁验证通过，驾驶舱、数据中心、策略知识库和导入入口均可正常打开。
3. 云端登录门禁模拟验证通过，未登录状态无法访问受保护接口。
4. 管理员账号登录验证通过，可访问受保护能力。
5. 试用者账号登录验证通过，写入、导入、同步等管理类操作被限制。
6. 云端旧登录方式绕过测试通过，服务器开启云端登录时仅允许用户名与密码登录。
