# MMN研发档案

本文档目录用于长期保存 MMN 汽车营销引擎的研发记录、问题修复记录、流程优化记录和版本演进说明。

自 2026-06-27 起，MMN研发团队执行以下归档规范：

1. 每完成一个功能、修复一个问题或优化一次流程，必须新增一份研发记录。
2. 研发记录以日期和版本号命名，确保可追溯、可检索、可审计。
3. 文档内容必须覆盖研发日期、版本号、需求背景、问题分析、技术方案、功能实现、修改模块、测试结果、版本变更说明及后续计划。
4. 文档必须采用企业研发档案口径，保持专业、客观、完整。
5. 文档不得记录与正式研发交付无关的信息。

## 命名规范

推荐格式：

`YYYY-MM-DD_v版本号_功能或问题摘要.md`

示例：

`2026-06-27_v1.1_驾驶舱导入入口与核心竞品显示优化.md`

## 目录结构

- `README.md`：研发档案管理规范
- `模板.md`：研发记录标准模板
- `YYYY-MM-DD_v版本号_*.md`：具体研发记录

## 维护责任

研发记录由 MMN研发团队在每次版本变更完成后同步归档，并随代码版本一并提交保存。
