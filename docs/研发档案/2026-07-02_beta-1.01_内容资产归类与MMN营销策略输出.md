# beta 1.01 内容资产归类与MMN营销策略输出

## 更新目标

内容资产中心不再只展示抓取后的数量看板，而是在抓取/同步后完成两件事：

1. 对抖音、小红书内容进行汽车营销语义归类。
2. 基于归类结果与上游三大板块输出 MMN 营销策略，并保留 Qwen + DeepSeek 交叉验证过程。

## 更新内容

### 0. 驾驶舱数据预览外显收敛

- 驾驶舱内“声量数据中心”预览标题改为“导入数据结构预览”。
- 摘要卡不再显示“当前车型样本 / 本品样本”等样本数量。
- 预览表格移除“样本”列，只保留车型、平台、赛道、标签、情绪。

### 0.1 垂媒资产库回填

- `/api/vertical-assets` 不再只返回统计，也返回长期沉淀的正反向关系 items 和来源 sources。
- 垂媒竞争格局页面如果本地看板为空，会自动从后端垂媒车型资产库恢复数据。
- 清空当前看板不再造成“已有资产看起来消失”的误解，长期资产库仍可回填页面。

### 1. 抓取后内容归类

- 新增前端二次归类层：历史已同步内容也会重新进入 MMN 营销标签体系。
- 新增后端导入归类增强：新导入 Excel 会同时使用标题、搜索词、话题、作者和平台字段判断。
- 默认兜底从“其他内容”改为“综合评测”，避免大量内容无法进入策略判断。
- 归类标签覆盖：
  - 价格权益
  - 购买阻塞点
  - 竞品关系
  - 上市发布
  - 智驾科技
  - 动力操控
  - 空间舒适
  - 续航补能
  - 安全质量
  - 身份表达
  - 用户口碑
  - 流量热点
  - 综合评测

### 2. MMN营销策略输出

- 内容资产中心新增“MMN策略输出”面板。
- 面板位置在自动抓取矩阵下方、KPI看板上方，优先展示策略结论。
- 策略上下文包含：
  - 决策驾驶舱核心指标、优先标签和诊断
  - 声量数据中心的平台、赛道、标签和情绪结构
  - 垂媒竞争格局的最新正反向关系
  - 本品和竞品车型
  - 抖音/小红书抓取任务
  - 内容分类结构
  - 平台分布
  - 车型内容资产结构
  - 高互动内容
  - 购买阻塞点
  - RAG召回片段
- 点击“生成/刷新MMN策略”会调用 `/api/ai/fusion-strategy`。
- 同步抓取结果、手动导入内容资产、启动抓取任务后会自动刷新策略。
- 外显策略只保留“核心营销结论 / 三大数据依据 / 营销动作 / KPI”，不展示“数据缺口”。

### 3. 交叉验证展示原则

- 对用户外显的主结果统一为“MMN模型输出策略”。
- Qwen 与 DeepSeek 过程记录只放在“查看MMN交叉验证过程”折叠区。
- 当任一模型不可用时，页面显示“MMN单模型 + 规则复核”或“MMN规则兜底”，不把底层模型作为主品牌外显。
- 内容资产策略页的底层提示词已单独约束：不输出“数据缺口 / 依据不足 / 尚未同步 / 尚未创建任务”等内部质量词。

## 验证重点

- 旧的“其他内容”数据在前端渲染时会重新归类。
- 新导入内容会在后端导入时获得更稳定的营销标签。
- MMN策略面板可以在没有模型返回时使用三大上游数据的本地策略兜底，页面不留空。
- 浏览器缓存号更新为 `beta-1.01-content-strategy-3`。
