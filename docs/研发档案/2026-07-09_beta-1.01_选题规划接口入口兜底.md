# 2026-07-09 beta-1.01 选题规划接口入口兜底

## 背景

用户在策略驾驶舱点击“MMN深度生成”时，页面提示“当前页面没有命中MMN后端接口”。排查发现部分入口的 `/api` 返回 HTML 或备案拦截页，而非 MMN 后端 JSON。

## 修复

- 前端 `api()` 在相对 `/api` 返回 HTML、403 或 404 时，自动重试公开后端 `http://121.40.60.90`。
- 策略驾驶舱选题规划新增浏览器本地兜底：如果深度策略接口与 `topic_planning_engine` 都不可用，也会基于当前车型、上市阶段、传播目标、竞品、预算和目标人群生成基础选题规划。
- 兜底规划包含选题卡片、传播阶段、达人匹配、Brief 要点、内容排期和策略结论，避免页面只显示失败。
- 前端资源版本升至 `beta-1.01-topic-planning-5`。

## 规则

车型传播选题规划器必须优先使用 MMN 深度策略链路；链路不可用时使用 `topic_planning_engine`；后端入口不可用时使用前端兜底规划，保证用户无论如何能看到至少几组选题。
