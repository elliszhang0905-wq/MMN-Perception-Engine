# 2026-07-02 beta 1.01 Chrome插件自动驱动抓取

## 更新目标

内容资产中心的 `开始抓取` 必须是自动驱动 Chrome 采集插件，而不是只打开平台页面等待人工操作。

## 实现内容

- 新增后端接口 `POST /api/social-plugin/auto-crawl`。
- 前端 `开始抓取` 改为调用自动驱动接口。
- 后端通过本机 Apple Events 驱动 Google Chrome：
  - 打开对应平台的车型搜索页。
  - 触发社媒助手 Chrome 插件快捷键 `Option + C`。
  - 唤起插件采集侧边栏，使采集任务进入插件执行入口。
- 前端槽位状态新增 `自动驱动中`，区别于旧的“采集任务已打开”。

## 当前边界

当前安装的社媒助手插件没有开放 `externally_connectable`，网页无法直接通过 `chrome.runtime.sendMessage` 调用插件内部采集函数。因此本次采用本机 Chrome 自动化桥：

- 需要 Chrome 开启 `显示 > 开发者 > 允许 Apple 事件中的 JavaScript`。
- 插件采集完成后，仍通过 `同步结果` 将最新导出沉淀为内容资产。
- 后续若插件开放外部消息接口，可将 `auto-crawl` 从 Apple Events RPA 升级为直接插件 API 调用。

## 验证记录

- Chrome Apple Events：已验证可执行。
- 后端语法：已通过 `python3 -m py_compile server.py`。
- 前端脚本语法：已通过系统 JavaScript 解释器加载 `app.js`。
- 自动驱动接口：已通过 `POST /api/social-plugin/auto-crawl`，样例 `智己LS8 汽车评测` 成功返回任务 ID、平台搜索 URL 和插件版本信息。
