# MMN车型资产月度撞库机制

## 研发日期

2026-06-27

## 版本号

v1.2.6

## 需求背景

MMN 汽车营销引擎需要长期维护稳定、准确、可追溯的品牌与车型资产主库。随着用户持续导入声量、垂媒正反向排名、达人、内容和车型判断数据，系统必须具备定期更新品牌车型归属、别名合并和新车型认领的能力。

## 问题分析

现有车型资产来源较多，存在以下风险：

1. 新增车型无法及时归入正确品牌。
2. 部分车型名与品牌名相似，容易被误判为品牌。
3. 中英文别名、能源版本和车系后缀可能造成重复资产。
4. 未确认资产不应长期作为前台品牌展示。
5. 车型资产需要定期与公开标准源进行校验。

## 技术方案

1. 建立 MMN 车型资产月度撞库脚本。
2. 每次撞库保存原始载荷、载荷哈希和处理报告。
3. 将品牌、车型、能源标识写入 MMN 车型资产主库。
4. 前台只展示 MMN 品牌与车型资产，不展示外部来源名称。
5. 定时任务默认每月 1 日 03:10 执行一次。
6. 撞库结果进入后台溯源和质量校验链路。

## 功能实现

1. 新增 `scripts/sync_mmn_vehicle_assets.py`。
2. 新增 `mmn_vehicle_asset_sync_runs` 运行记录表。
3. 更新 `model_identity_assets` 与 `vehicle_assets` 写入逻辑。
4. 更新定时任务脚本，支持月度自动撞库。
5. 更新环境变量模板，支持调整每月执行日期和时间。
6. 更新部署文档，说明月度车型资产维护机制。

## 测试结果

已完成：

1. 手动执行月度撞库脚本通过。
2. 成功解析 554 个品牌、5667 个车型。
3. 成功写入 MMN 车型资产主库。
4. 成功生成月度撞库报告。
5. 前台车型库保持 MMN 数据资产命名，不展示外部来源名称。
