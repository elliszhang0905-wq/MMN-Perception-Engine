# beta 1.01 内容资产抓取与策略链路修复

更新时间：2026-07-03 13:45

## 本次修复目标

围绕内容资产中心的自动抓取体验、车型归属、标签看板和 MMN 策略输出链路做系统修复，避免抓取结果停留在普通数据看板层面。

## 更新内容

1. 自动抓取界面重构
   - 抖音 / 小红书抓取卡片改为车型资产工作台样式。
   - 不再外显插件导出文件名，避免把“盖世汽车”等后台文件名误认为内容来源。
   - 卡片显示车型、抓取状态、车型内容沉淀数量和非本车型内容过滤结果。
   - 自动抓取关键词统一为纯车型名，不再拼接“汽车评测”等后缀，避免搜索意图被窄化。

2. 小红书 / 抖音看板逻辑调整
   - 平台看板从“全平台分类统计”改为“按车型拆分标签资产”。
   - 每台车型独立展示 Top 标签和内容数量。
   - 小红书看板用于展示抓取车型的种草标签结构，不再只是泛分类图表。

3. 删除无策略链路的车型对比结构表
   - 取消“本品与核心竞品内容资产结构”表。
   - 替换为“MMN策略链路”，展示从抓取、语义归类、交叉质检到策略输出的路径。

4. 内容明细表修正
   - “资产角色”改为“资产车型”，不再显示“竞品1 / 本品1”。
   - 内容明细表不再外显作者列，避免作者识别状态占据看板注意力。

5. 抓取结果进入策略输出链路
   - 同步抓取结果后会按车型过滤内容，避免同一份导出被套到多个车型。
   - 本品和竞品内容沉淀后，可进入 MMN 交叉质检和策略输出。
   - 同步完成后继续触发 MMN 策略刷新。

## 验证结果

- 本地 Chrome 验证内容资产中心可正常点击进入。
- 页面无控制台错误。
- 页面不再出现“盖世汽车”后台文件名。
- 小红书车型标签看板正常生成车型卡片。
- 小红书 / 抖音车型标签看板的标签数值字段已修复，不再出现 `undefined`。
- MMN策略链路正常生成 4 个步骤。
- 明细表表头已更新为“资产车型”，并移除作者列。
- 点击小红书本品抓取时，接口 query 已验证为纯车型名。
