# beta 1.01｜BF工厂 P0

## 更新目标

在 MMN 当前架构内建立品牌商业化内容 Brief 的完整闭环：客户需求与原始资料进入系统后，完成车型/竞品/传播阶段诊断、可执行 BF 生成、达人商单交付、最终版回流和策略资产沉淀。

BF 在本功能中始终指品牌客户商业化内容 Brief，不是通用文档总结或普通自动写作。

## 关键产品判断

探店BF、云评/口播BF、高质感摄影BF只是首批种子范式，不是封闭的三类模板。系统采用两层结构：

1. A–F 六层字段作为稳定的知识本体，保证检索、标签、溯源和人工校正可持续。
2. 最终交付章节按项目阶段、传播目标、达人类型、平台、内容方向和历史优质样本动态组合，未知或混合需求进入 `CUSTOM` 范式并可从优质终稿学习新的章节意图。

因此，未来新增女性体验、竞品同场景对比、车展动态素材采集、KOS转化或其他新需求时，不需要增加硬编码的 BF 类型枚举。

## 页面与入口

- 前台：核心工作流 → MMN策略输出 → BF工厂。
- BF工厂：新建BF、达人BF生成器、探店种子入口、云评/口播种子入口、高质感摄影种子入口、脚本框架、拍摄执行清单、Word导出。
- 后台：资产沉淀 → BF资产库。
- BF资产库：原始文件、结构化样本、优质样本、反例/禁用样本、甲方口径、拍摄规范、车务规范、表达红线、素材链接。
- RAG策略台继续负责底层检索和证据链，不作为BF生成器前台入口。

编辑器支持正文编辑及 BF 类型、摘要、核心策略判断、内容方向、风险提示和标签的人工校正。每次保存生成新版本，并把人工修改写入字段溯源。

## 数据结构

新增 SQLite 表：

- `bf_projects`：组织、客户隔离标识、项目、品牌和车型。
- `bf_documents` / `bf_parse_jobs` / `bf_segments`：原始文件、解析状态、页码/段落/表格块。
- `bf_briefs` / `bf_brief_versions` / `bf_field_provenance`：BF主记录、原始生成/人工/最终版本和字段来源。
- `bf_knowledge_chunks`：脱敏后的方法论、口径、拍摄、车务、红线和素材类检索片段。
- `bf_template_profiles`：种子范式和从优质自定义终稿学习的开放范式。
- `bf_generation_runs` / `bf_model_calls` / `bf_exports`：生成、模型调用和导出审计。

结构化 JSON Schema 版本为 `1.0.0`，稳定层为 `strategy`、`product`、`content`、`execution`、`risk`、`materials`，另含 `classification`、`tags`、`provenance` 和 `extraction`。前端和集成方可通过 `GET /api/bf/schema` 读取契约。

## 文件解析

P0 支持 `.doc/.docx/.ppt/.pptx/.pdf/.jpg/.jpeg/.png/.webp/.xls/.xlsx/.csv/.txt/.md`。标准 OOXML、文本和基础表格优先本地解析；扫描件和图片使用 OCR；旧版 Office 文件通过 LibreOffice 转换。依赖不可用时返回明确解析警告，不静默伪造字段。

Docker 增加 LibreOffice Writer/Impress/Calc、中文 OCR 和 Noto CJK 字体。Word 导出使用系统可用的中文字体，macOS 默认为 Hiragino Sans GB，Linux/Docker 默认为 Noto Sans CJK SC。

## 生成与学习链路

1. 解析上传资料并生成带来源位置的 A–F 结构化结果。
2. 正向检索优质/普通样本；反例只进入风险上下文；禁用样本完全排除。
3. DeepSeek负责内部策略判断，Qwen负责中文章节初稿，DeepSeek负责逻辑、竞品和风险复核。
4. 模型异常时输出 `EDITABLE_DEGRADED`，保留可编辑的本地策略和章节结果。
5. 人工保存最终版后生成 RAG 片段；优质的 `CUSTOM` 终稿可新增脱敏范式，只保存通用章节意图，不保存客户原文。

## 安全与合规

- 原始文件按 `org_id/client_key/project_id/document_id` 隔离存储，文件权限设为仅服务账户可读写。
- 文件名净化、扩展名与文件头双校验、30MB大小限制，拒绝路径穿越和格式伪装。
- 外部模型调用前默认脱敏；客户/品牌、车型、竞品、预算价格、未公开口径、联系人、电话、邮箱、URL、网盘提取码等进入模型前替换。
- 前台保留显式脱敏开关；关闭时调用记录仍只保存脱敏后的审计输入，并标注 `EXPLICIT_OFF`。
- 不跨客户召回原始 BF；优质自定义范式名称会移除客户、品牌、车型和竞品标识。
- 所有生成字段保留原始文件、页码/段落、字段路径或“策略推断/人工修改”来源。

- 发布门禁覆盖 BF 一级入口、开放式生成界面、人工业务字段校正和项目范围文件上传。
- Word 样例用系统 Quick Look 验证中文字体和首屏，用文档渲染器检查全部页面排版和 PDF 文本层；未发现裁切或重叠。
