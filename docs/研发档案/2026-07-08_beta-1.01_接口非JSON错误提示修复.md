# MMN接口非JSON错误提示修复研发记录

## 研发日期

2026-07-08

## 版本号

beta 1.01

## 需求背景

车型传播选题规划器在云端使用时，当前端请求没有拿到标准接口数据，而是收到页面内容时，页面会暴露浏览器原始解析错误，影响用户判断。

## 问题分析

前端通用接口函数默认直接执行 JSON 解析。若服务器返回登录页、重定向页或其他HTML页面，错误会显示为底层解析异常，无法指导用户下一步处理。

## 技术方案

调整前端通用接口函数，先读取响应文本，再进行JSON解析。若解析失败，按状态码和响应类型输出可理解的业务提示；若接口返回错误状态，则保留后端结构化错误。

## 功能实现

- 非JSON响应不再显示底层解析异常。
- 登录失效或权限异常提示用户刷新并重新登录。
- 页面内容误返回时提示当前入口未命中MMN接口。
