# 2026-07-29 beta 1.03 本竞品抖音内容雷达与可信播放量榜单

## 版本与范围

- 发布候选：`beta-1.03-20260729-douyin-vehicle-radar-1`
- 页面位置：车型综合决策报告下方、现有“抖音汽车热点”上方
- 运行方式：用户手动选择 7、14 或 30 天后启动
- 数据对象：当前产品评价数据中的本品和核心竞品

## 实现

1. 新增车型雷达持久化模块，保存项目、运行、内容观察和已验证播放量快照。
2. 公开搜索只承担召回；播放量由独立多视频统计接口补齐，搜索结果中的未验证 `0` 不再作为事实。
3. 每批最多统计 50 个视频；批次失败时递归拆分并限制追加请求次数，使单条异常不会抹掉整批有效结果。
4. 正式榜单仅接收 `views=verified` 的内容；缺失值进入“待补热度”，不补 `0`、不参与排序。
5. 内容按本品、竞品、本竞品对比、属性话题和人工复核边界分类，跨关键词按平台内容 ID 去重。
6. 策略准备度由车型覆盖、播放量覆盖率和对比/属性证据共同确定；证据不足时不发布确定性建议。
7. 页面不外显数据供应商、技术接口、调用价格、内部数据版本和原始导入文件键。
8. 同批修复产品评价目录恢复逻辑，避免车型库退化为单车型。

## 本地真实验收

- 智己 LS6 7 天运行在一次搜索失败时正确失败关闭，没有产生伪排行。
- 另一真实运行先因单条异常停在部分完成；仅重试播放量后完成 10 条正式榜单，播放量覆盖率 100%。
- 完成样本包括本品 7 条、竞品 2 条、本竞品对比 1 条；策略准备度为可进入下一步。
- 1440px 与 390px 均无页面横向溢出、控制台错误或失败请求；移动端分类页签保持横向可读。
- 雷达专项 84 项 Python 测试与前端合同测试通过。

## 证据边界

- 榜单代表指定观察窗内，经公开搜索召回并完成播放量验证的相关内容，不代表抖音全平台全库。
- 播放量、互动量和内容相关性分别展示；热度不直接等于购车需求、线索或销量。
- 生产当前产品评价上下文为智己L6，本轮没有同步本地智己LS6产品评价文件；两套数据不得混写。
