# MMN Perception Engine 研发记录

## 研发日期
2026-06-27

## 版本号
v1.2.9

## 需求背景
MMN Perception Engine 云端演示环境需要接入正式测试域名 `mmnsh.com`，用于后续移动端、客户设备及异地访问验证。当前阶段仅用于内部测试，不开放正式客户访问。

## 问题分析
云端服务已具备 Docker 化运行能力，并可通过 ECS 端口承接 HTTP 请求。但域名解析尚未指向目标 ECS，且服务网关配置仍为通用兜底域名，需要补充域名承接配置，并保留后续 HTTPS 接入空间。

## 技术方案
1. 将 Web 网关服务配置为同时承接 `mmnsh.com` 与 `www.mmnsh.com`。
2. 云端环境变量统一使用域名作为公开访问地址。
3. 保持登录与权限体系不变。
4. HTTPS 证书签发在域名解析生效后执行，避免证书申请失败。

## 功能实现
- 更新 Nginx 服务域名承接配置。
- 预留 80/443 标准端口访问路径。
- 明确域名解析与 HTTPS 配置的执行顺序。

## 修改模块
- `deploy/nginx.conf`
- 云端 `.env` 公开访问地址配置
- 云端防火墙端口配置

## 测试结果
- 云端容器服务运行正常。
- 已完成 `mmnsh.com` 与 `www.mmnsh.com` 的 A 记录配置，均指向 ECS 公网地址。
- 阿里云权威 DNS 返回结果正确。
- ECS 安全组已开放公网入方向 HTTP 与 HTTPS 访问规则。
- 公网 HTTP 访问已返回 200 状态码，云端 Web 网关可正常承接请求。

## 版本变更说明
本版本为域名接入准备版本，不改变业务功能、不调整数据结构、不影响本地开发环境。

3. 完成移动端与客户设备访问验证。
4. 后续结合备案进度，推进正式客户访问环境。
