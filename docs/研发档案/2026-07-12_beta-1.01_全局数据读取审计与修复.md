# beta 1.01 全局数据读取审计与修复

日期：2026-07-12
版本码：`beta-1.01-data-audit-1`

## 目标

面向汽车品牌市场营销负责人的决策驾驶舱，确保数据链在进入策略判断前满足四个条件：原始值读对、聚合口径一致、缺失不伪装成 0、不同客户空间互不串读。

## 审计结论

本轮确认并修复的不是单一“小米智驾显示数据不足”问题，而是解析、聚合、持久化和浏览器恢复四层问题的组合：

1. 产品评价表的整体 NSR 曾被相邻垂媒区块覆盖。
2. JavaScript `Number(null)` 与后端默认值曾把缺失数据伪装成真实 0。
3. 汽车之家专用解析和通用解析同时命中，8 个周期被重复成 16 个周期。
4. Excel 日期序列、富文本、多单位数字及新版社媒助手表头存在兼容缺口。
5. 竞品对比曾用“本品跨源均值”对“竞品单平台最高值”，并可能截断并列车型。
6. 垂媒、机会地图与浏览器缓存曾缺少完整的客户空间隔离。
7. 页面刷新后，机会地图任务、产品资料和执行闭环未自动恢复，旧异步结果可能覆盖新车型。

## 修复后的数据不变量

| 数据层 | 不变量 |
| --- | --- |
| 产品评价 | 整体 NSR 只读连续全网区块；属性 NSR 按来源独立；缺少必要区块即拒绝 |
| 数值 | 空值、破折号和无效文本为缺失；真实 0、负数、百分比、万/k/w 与科学计数法按原义保留 |
| 垂媒周数据 | 专用格式只解析一次；周期按规范时间排序；同文件重导替换旧快照 |
| 社媒助手 | Excel 日期转真实时间；无标题时只使用原表可追溯文本；博主字段精确匹配 |
| 竞品聚合 | 本品与竞品均按相同来源均值；并列名次完整保留；覆盖率按唯一来源计算 |
| 客户隔离 | 服务端按 `org_id + edition`，机会地图与浏览器上下文再按 `model` 隔离 |
| 策略闭环 | 产品资料、后台任务、执行周期和监测反馈在同一上下文恢复，旧请求不得覆盖新上下文 |

## 真实文件对账

- 5 款车型、15 个属性、3 个属性来源，共 207 条属性 NSR。
- 2 个真实 0、18 个真实负值均保留；破折号均作为缺失处理。

### 汽车之家周排名

- 源表 8 个周期、1,200 条关系；修复后解析结果仍为 8 个周期、1,200 条，无缺失、无额外记录。
- 生产库副本由 4,467 条关系精确去重为 3,267 条：汽车之家 1,200 条、懂车帝 2,067 条。
- 初始化、管理员认领及同文件再次导入后均保持 3,267 条，验证迁移与重导幂等。
