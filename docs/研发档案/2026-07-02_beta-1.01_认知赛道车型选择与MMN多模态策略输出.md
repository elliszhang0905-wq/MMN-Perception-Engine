# beta 1.01 更新记录：认知赛道车型选择与MMN多模态策略输出

## 更新范围
- 页面：认知赛道诊断
- 版本：beta 1.01
- 日期：2026-07-02

## 更新内容
1. 认知赛道诊断页新增品牌与车型选择区。
   - 优先从声量数据中心已有车型生成可选项。
   - 垂媒竞争格局、车型判断资产作为补充来源。
   - 未完成标准品牌归属的车型不会被隐藏，会进入待确认品牌。

2. 认知赛道诊断页新增 MMN 多模态策略输出区。
   - 外显名称统一为“MMN多模态策略输出”。
   - 策略上下文调用决策驾驶舱、声量数据中心、垂媒竞争格局。
   - 支持 Qwen 主策略与 DeepSeek 策略质检的交叉验证过程展示。

3. 服务端新增认知赛道专用策略提示与融合规则。
   - 输出结构固定为：核心认知判断、资产负债机会、策略动作、KPI。
   - 底层模型名称仅出现在交叉验证过程，不作为主策略标题。
   - 本地规则兜底也保持同一套策略表达，避免页面空白。

## 验收标准
- 进入认知赛道诊断页后，顶部必须展示可选择的品牌与车型。
- 只要系统中存在相关车型数据，就应出现在选择器中。
- 切换车型后，表格和 MMN 策略输出同步切换。
- 生成策略时必须调用 `/api/ai/fusion-strategy`，并保留 Qwen + DeepSeek 交叉验证记录。
