# 达人内容学习与蒸馏流水线V1研发记录

## 研发日期
2026-07-05

## 版本号
v1.0-beta 1.01

## 需求背景
原达人蒸馏模块已经具备内容导入和达人DNA资产包能力，但整体仍偏向样本片段与RAG证据展示。业务使用需要进一步形成完整流水线：从达人主页或作品链接、授权文件或人工整理样本进入，完成公开内容采集、文本读取、结构化拆解、达人DNA资产沉淀和业务资产调用。

## 问题分析
1. 旧模块对单条内容的结构化拆解不够明确，无法直接看到标题、核心选题、开头钩子、主观点、论证结构和可迁移方法。
2. 达人DNA资产包缺少可直接调用的业务资产字段，例如脚本模板、30天选题库、账号孵化建议和客户brief模板。
3. 页面调用入口过多且偏工具化，需要聚焦为脚本生成、账号孵化和咨询检索三类核心业务动作。
4. 公开平台采集存在登录、验证码、付费墙和风控限制，系统必须保留合规停止与人工补充机制。

## 技术方案
1. 在内容能力片段表中新增 `content_breakdown_json` 字段，用于保存单条内容拆解结果。
2. 对每条内容生成结构化拆解：标题、核心选题、开头钩子、主观点、论证结构、专业知识点、场景标签、表达风格、结尾方式、可迁移方法、不可复制风险。
3. 对达人资产包新增脚本模板、语言风格规则、信任来源、30天选题库、账号孵化建议、客户brief模板和资产状态。
4. 前端页面升级为“达人内容学习与蒸馏流水线”，保留合规说明，并将调用入口收敛为三类核心业务入口。
5. RAG证据区展示单条内容结构化拆解，不再作为主交付物。

## 功能实现
- 新增单条内容结构化拆解字段。
- 新增达人DNA业务资产字段。
- 新增脚本模板、30天选题库、账号孵化建议、客户brief模板。
- 页面新增三个核心调用入口：
  - 按该达人风格生成新脚本
  - 用该达人作为benchmark孵化新账号
  - 按客户课题检索适配达人风格
- 保留公开采集合规边界：只读取公开可见内容，遇到登录、验证码、付费墙或平台风控时停止。
