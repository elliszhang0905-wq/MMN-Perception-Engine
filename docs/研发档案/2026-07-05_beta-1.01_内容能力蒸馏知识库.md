# MMN Perception Engine 研发记录

## 研发日期
2026-07-05

## 版本号
beta-1.01

## 需求背景
内容资产中心需要支持对抖音、小红书、B站等公开内容样本进行能力沉淀，将用户手动导入的视频标题、口播文案、描述、互动数据、评论摘要和链接等信息转化为可检索、可组合调用的长期内容能力知识资产。该能力用于支持策略报告、达人 brief、短视频脚本、账号孵化方案和竞品话术等业务场景。

## 问题分析
现有内容资产中心已具备内容看板、达人库、创始人蒸馏和博主/达人蒸馏能力，但尚缺少一个面向多平台、多账号、多主题样本的通用内容能力知识库。若继续将样本混入车型内容库或达人库，容易造成数据边界不清、标签不可组合、RAG调用不可追溯等问题。

## 技术方案
1. 新增独立数据表保存内容能力来源样本与蒸馏后的 RAG 能力片段。
2. 复用系统已有通用文件解析能力，支持 CSV、Excel、JSON、TXT、Markdown。
3. 建立平台、账号、车型、品牌、技术、场景、情绪、脚本结构、表达风格、专业领域、适用任务、可信度、可迁移性标签体系。
4. 通过规则化标签识别、分段、去重和本地向量索引字段，形成第一版稳定可用的内容能力知识库。
5. 将内容能力知识库接入现有 RAG 检索池，供策略报告、达人 brief、短视频脚本、账号孵化和竞品话术模块调用。

## 功能实现
1. 新增「内容能力蒸馏库」入口，集成在内容资产中心标签栏。
2. 新增「导入内容样本」能力，支持用户手动导入多格式文件。
3. 新增组合标签检索，支持按技术、场景、表达风格、脚本结构、专业领域和适用任务组合筛选。
4. 新增内容能力卡片，展示脚本风格、方法论迁移、可调用任务和 RAG 片段。
5. 输出内容明确保留合规边界：仅迁移方法论，不复制原文、不仿写、不冒充原账号。

## 修改模块
- `server.py`：新增内容能力知识库数据表、导入解析、标签生成、分段、向量字段、RAG payload 和接口。
- `index.html`：新增内容资产中心子页与导入控件。
- `app.js`：新增前端状态、加载、导入、标签检索、渲染逻辑，并接入 RAG 检索池。
- `style.css`：新增内容能力知识库页面样式。

## 版本变更说明
本次变更为内容资产中心新增长期知识资产模块，不改变原有车型内容库、达人库、创始人蒸馏和博主/达人蒸馏数据结构，不影响现有页面入口和原有导入流程。
