# beta 1.02 决策驾驶舱与博主蒸馏交付闭环

## 发布信息

- 日期：2026-07-20
- 最终版本码：`beta-1.02-20260720-cockpit-creator-2`
- 发布验收修复：新导入达人在完整能力卡交付后同步发布到脚本生成选择器，避免能力卡与下游交付资产断链。
- 发布范围：决策驾驶舱、管理层集团看板、销量预警、达人蒸馏、原创脚本工作台

## 决策驾驶舱

- 新增跟随销量预警车型的线索看板，并将车型选择同步到 T 周期、产品评价、NSR、竞品与策略模块。
- 线索、订单和销量预警使用统一车型上下文；缺少平台来源、内容 ID 和内容标签时只显示数据缺口，不生成内容因果结论。
- 新能源销量预警按同尺寸 × 新能源市场计算，新能源统一包含纯电、增程和插电混动；非新能源按同尺寸 × 非新能源市场计算。
- 集团高管摘要改为读取同一已发布数据批次。两路独立复核未完成或未通过时，摘要与品牌策略保持不发布。
- 增加周度官方市场数据刷新、周二至周五补抓和月度销量刷新检查；校验失败时保留上一期已发布数据。

## 博主蒸馏与内容交付

- 社媒助手文件导入改为持久化四阶段任务：导入、蒸馏、分析、交付。
- 导入任务保存文件副本、达人身份、阶段进度、失败原因和重试状态；刷新页面后可恢复。
- 完整能力卡交付前校验达人名称、样本量、阶段历史、画像与资产完整性，避免新达人错误关联已有档案。
- 新增达人方法论原创脚本工作台，支持选择达人和抖音、视频号、B站、小红书四个平台。
- 交付内容包括标题、开头钩子、完整口播稿、字幕重点、画面建议、一键复制、Word 导出和修改要求重新生成。
- 脚本任务持久化记录进度、版本、失败原因和重试；三阶段分别负责成稿、独立复核和自然表达优化。
- 品牌、车型和传播重点只作为创意简报；未取得证据的车型能力必须改写为到店、拍摄或实测验证动作。

## 数据与发布边界

- 不清空或覆盖 `data/commercial_demo.db`、达人导入文件、销量周期和人工复核记录。
- 运行日志、临时截图、数据库备份和任务缓存不进入 Git 仓库。
- 服务器发布前分别备份代码、环境配置和持久化数据；部署后验证业务接口、前端资源、容器状态与错误日志。

## 回滚

- Git 回滚目标：本次功能提交的上一提交。
- 服务器回滚：恢复发布前代码归档和持久化数据备份，再执行 `MMN_SKIP_GIT_PULL=true bash deploy.sh`。
