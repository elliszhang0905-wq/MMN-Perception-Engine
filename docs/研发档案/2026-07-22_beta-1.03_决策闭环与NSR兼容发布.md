# beta 1.03 决策闭环与 NSR 兼容发布

## 发布范围

- 版本标识：`beta-1.03-20260722-decision-closure-1`。
- 车型全驾驶舱综合决策：八表面冻结快照、不可变报告、冲突裁决、Action、Result、Learning 与 Know-how 候选门禁。
- 销量预警跨域归因：同一锁定证据包进入三路独立复核，只有共同证据、方向一致和完整门禁成立时发布综合判断。
- 卖点机会决策台：五类事实边界、三路独立建议、确定性综合、人工裁决与动作门禁。
- 竞争趋势：稀疏周期连线和横轴标签可读性修复；正反向三路结果只发布唯一融合结论。
- 策略汇报资料包：冻结当前驾驶舱上下文，形成可追溯资料包，不在系统内生成演示文稿。
- 智己 L6 产品评价兼容：把旧版属性正负聚合行无损归一化为显式属性 NSR，让上层摘要和下层机会地图共用同一合同。

## 业务边界

- 三路一致不等于因果证明；声量不等于需求，订单目标达成率不等于同批线索转化率。
- 缺失、冲突和未验证事实保持缺失、冲突或待人工复核，不使用模型补齐。
- Learning 必须来自真实 Action 与 Result 并通过人工裁决；Know-how 默认至少需要两个已批准 Learning。
- 旧版数据只有满足已登记的字段、情绪和有效样本合同才自动归一化；未知格式保持缺数，不猜测 NSR。
