# MMN Perception Engine 研发记录

## 研发日期
2026-06-28

## 版本号
v1.0-beta

## 需求背景
内容资产中心需要统一承载内容看板、达人库、创始人公开表达蒸馏、博主/达人专业能力蒸馏等内容资产能力，减少左侧功能栏分散入口，形成围绕内容资产的一体化工作台。

## 问题分析
原有“创始人蒸馏”和“博主能力蒸馏 Skill”以独立左侧模块呈现，与内容资产中心、达人库之间的业务关系不够集中。随着后续蒸馏对象增加，需要在内容资产中心内增加对象选择机制，支持按博主、达人或高管对象查看对应蒸馏结果。

## 技术方案
1. 将创始人蒸馏与博主/达人蒸馏入口整合进内容资产中心二级标签栏。
2. 保留原有数据结构、模型调用链路和入库逻辑，仅调整前端入口与视图挂载方式。
3. 增加博主/达人选择下拉框，根据已入库样本和能力画像自动生成可选对象。
4. 选择某一蒸馏对象后，仅展示该对象对应的样本拆解、能力画像和 RAG 知识片段。

## 功能实现
- 内容资产中心新增“创始人蒸馏”“博主/达人蒸馏”两个标签。
- 左侧导航移除独立“创始人蒸馏”和“博主能力蒸馏 Skill”入口。
- 原有蒸馏模块运行时迁移至内容资产中心内部容器，不改变后端接口。
- 博主/达人蒸馏新增对象选择器，支持后续多对象扩展。
- 切换到博主/达人蒸馏标签时自动刷新蒸馏数据。

## 修改模块
- 内容资产中心页面结构
- 内容资产中心二级标签切换逻辑
- 博主/达人蒸馏对象筛选逻辑
- 前端静态资源缓存版本

## 测试结果
1. 本地语法检查通过。
2. 浏览器自动化验证通过：内容资产中心标签栏显示五个入口。
3. 左侧导航已不再显示独立蒸馏模块。
4. 博主/达人蒸馏标签可打开，并显示“冷静的饺子”对象选择。
5. 已读取 30 条样本，能力画像可正常展示。
6. 创始人蒸馏标签可打开，原有页面内容可正常展示。

## 版本变更说明
本次变更属于前端信息架构优化，不改变数据库结构、不改变模型接口、不影响既有导入、蒸馏和 RAG 入库能力。

## 后续计划
1. 增加更多博主、达人、高管对象后，继续完善对象分组和搜索能力。
2. 将内容资产中心逐步升级为内容资产、达人资产、话术资产、专业 Skill 资产的统一入口。
3. 增加不同蒸馏对象之间的能力对比和可复用模板推荐。
