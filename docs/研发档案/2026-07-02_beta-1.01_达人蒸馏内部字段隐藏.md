# 达人蒸馏内部字段隐藏

## 研发日期

2026-07-02

## 版本号

beta 1.01 持续更新

## 需求背景

达人蒸馏页的“策略质检”和“Agent指令”属于 MMN 内部链路信息，不应在用户侧页面外显。用户侧应该看到能力画像、策略资产、脚本资产和可执行模板，而不是模型质检原文或内部 Agent Prompt。

## 问题分析

原页面在能力画像中展示了：

- 策略质检
- Agent指令

这两类内容对系统内部有价值，但对前台用户来说信息过重，也容易造成误解。

## 技术方案

后端字段继续保留，供 MMN 质检、RAG 和生成链路调用；前端达人蒸馏能力画像不再展示这两个字段。

## 功能实现

- 从达人蒸馏能力画像中移除“策略质检”展示。
- 从达人蒸馏能力画像中移除“Agent指令”展示。
- 前端脚本缓存号更新为 `beta-1.01-creator-assets-2`。

## 修改模块

- `app.js`
- `index.html`

## 测试结果

- 前端 JavaScript 语法检查通过。
- 页面仍保留能力定位、评价框架、术语体系、判断规则、短视频模板和客户报告模板。

## 版本变更说明

本次属于 beta 1.01 的前端展示修正，不改变数据库、不改变蒸馏结果结构、不影响 MMN 内部调用。

## 后续计划

后续所有内部链路字段默认遵循：后台保留、模型可用、前台不直接外显。
