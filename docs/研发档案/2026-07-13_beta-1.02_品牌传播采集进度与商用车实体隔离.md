# beta 1.02｜品牌传播采集进度与商用车实体隔离

## 背景

品牌传播穿透项目原有采集状态只显示“正在启动”，无法说明任务处于数据源采集、实体校验、竞品对齐还是快照入库阶段。同时，奔驰品牌宽搜曾将“梅赛德斯-奔驰卡车 / ABA6Plus”内容误归入乘用车品牌看板，造成品牌实体边界污染。

## 本次改动

1. 新增社媒采集异步任务与轮询接口，按真实完成阶段回传 0—100% 进度。
2. 项目配置区新增实际百分比、进度条和阶段说明；完成、运行、失败状态使用一致的可读反馈。
3. 采集范围由本品与最多 3 个竞品调整为本品与最多 5 个竞品，和品牌传播穿透项目展示口径一致。
4. 增加乘用车范围排除规则，识别奔驰卡车、戴姆勒卡车、Daimler Truck、ABA 系列商用车制动系统、重卡、牵引车、半挂车、商用车与客车信号。
5. 在在线采集、社媒助手导入、最终快照写入三层执行同一范围校验；最终写入采用阻断策略，避免绕过前置规则的数据进入数据库。

## 数据修复

- 已备份本地主数据库至 `../backups/commercial_demo.db.bak-20260713-commercial-vehicle-cleanup`。
- 已清理两份“上汽奥迪品牌传播穿透”历史快照中的 ABA6Plus / 奔驰卡车内容及其聚合词项。
- 最新正式快照由 195 条调整为 194 条唯一内容；平台构成为抖音 17 条、微博 109 条、小红书 68 条。

## 验证结果

- 社媒采集与品牌传播模块共 26 项测试通过。
- 驾驶舱界面检查通过，脚本语法检查通过。
- 本地接口返回 194 条唯一内容，商用车污染记录为 0。
- 真实浏览器确认进度数字、进度条、194 条快照口径正常，控制台无错误或警告。

## 产品边界

本次仅加强 MMN 汽车品牌营销数据的车型实体边界与任务透明度，不改变社媒证据的使用口径：公开社媒内容用于解释传播表达、争议与认知占位，不作为完整市场需求或成交证明。
