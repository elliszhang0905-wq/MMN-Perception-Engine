# 抖音逐视频证据链恢复修复工单

## 工单结论

- 类型：现有逐视频分析链路缺陷修复与生产发布
- 优先级：P0
- 状态：已授权实施
- 版本：`beta-1.03-20260730-douyin-video-evidence-chain-2`
- 影响面：本竞品抖音内容雷达 → 单条视频 → 生成/重新分析

## 问题与根因

智己 LS6 视频 `7660088055264546082` 在本地真实流程中结束为 `limited_analysis`，界面只显示“当前仅形成有限分析”。只读核对确认：

- 分享地址使用 `iesdouyin.com/share/video/...`，现有页面校验只接受 `douyin.com`。
- 服务端写入 `duration_ms`，媒体处理器读取 `media.durationMs`，长视频误入短音频通道并报“音频过长”。
- 页面与榜单内容未通过一致性取证后，未获得可用浏览器关键帧；直接媒体地址又被公网安全门禁拒绝。
- OCR 返回非结构化结果后没有形成可用证据。
- 最终只有标题与评论，字幕、关键帧、OCR、视觉证据均为 0；三路独立分析没有启动。
- 雷达卡片把所有非运行状态统一显示为“重新分析”，没有说明当前仍处在补取证据阶段。

## 目标

1. 对合法抖音分享地址进行安全归一化，并继续按平台内容 ID 校验页面一致性。
2. 修正媒体时长契约，使长视频进入长音频转写链路。
3. 优先使用受控浏览器关键帧形成视觉与 OCR 证据，不降低私网/保留地址拒绝规则。
4. 对结构化 OCR 输出提供一次同证据修复机会，失败时保持明确缺失状态。
5. 让用户能够区分“正在取证、证据不足、分析未启动、三路分析失败或完成”。
6. 完成测试、提交、GitHub 主线同步、本地更新、ECS 部署及真实业务验收。

## 范围

- `douyin_video_insights.py`：分享地址识别、标准页面地址与原始来源保留。
- `server.py`：媒体处理入参契约、证据获取与状态信息。
- `creator_distillation/media_processing.py`：时长兼容、关键帧优先、OCR 结构化修复。
- `douyin-vehicle-radar.js` 与对应样式：逐视频证据状态、缺失项与可执行按钮。
- 对应 Python、前端合同与真实流程测试。
- 发布状态、研发档案与交接记录。

## 非目标

- 不改变正式榜单的播放量核验与排序口径。
- 不自动批量分析榜单中的所有视频；仍只处理用户明确点击的单条内容。
- 不绕过私网、回环、保留地址和任意域名安全校验。
- 不用标题、评论或模型常识补写缺失的视频本体证据。
- 不覆盖本地或生产 SQLite；不回滚整表。
- 不把 `limited_analysis`、`manual_required` 或真实冲突伪装为完成。

## 工程契约

- 分享地址必须为 HTTPS、受支持的抖音域名，并能提取与当前榜单一致的平台内容 ID。
- 原始分享地址与归一化页面地址分别保存，便于追溯；地址可打开不等于已读取视频本体。
- 媒体时长在服务端与处理器之间使用单一兼容契约；超过 5 分钟必须走长音频转写。
- 浏览器关键帧必须来自匹配内容 ID 的实际播放页面，携带时间点与媒体指纹。
- 安全门禁继续拒绝私网、回环、链路本地、保留及多播地址；不得以扩大通配白名单解决取证失败。
- OCR 修复只处理同一次模型输出的结构，不新增不可追溯内容；仍无有效对象时记录缺失。
- 证据覆盖不足时不启动三路分析；达到门槛后，每路输出必须独立持久化并通过结构校验。
- 客户界面使用简体中文和中性能力标签，不显示供应商、模型名、密钥、原始内部错误或证据哈希。

## 验收矩阵

- 地址：`douyin.com/video/{id}` 与 `iesdouyin.com/share/video/{id}` 可归一化；非 HTTPS、非抖音域名、内容 ID 不一致均拒绝。
- 时长：超过 5 分钟的视频进入长音频链路；短视频保持原路径。
- 画面：浏览器关键帧优先于不可直接读取的媒体 URL，并保留真实时间点。
- OCR：标准 JSON 正常通过；包裹文本/首个完整对象可恢复；无有效对象时明确失败且不生成证据。
- 门禁：无视频本体仍为有限分析且三路运行数为 0；具备转写和视觉证据后才启动三路分析。
- 状态：用户看见取证阶段、缺失项、分析是否启动以及下一步按钮；刷新后状态保持。
- 桌面与移动：1440px、390px 下状态和操作不遮挡、无整体横向溢出。
- 安全：私网/保留地址仍被拒绝，外部界面不泄露内部能力名称。
- 数据：部署前后主库及相关持久库通过 `quick_check` 与逐表、主键、字段逻辑比对；验收写入按记录 ID 与内容哈希精确清理。
