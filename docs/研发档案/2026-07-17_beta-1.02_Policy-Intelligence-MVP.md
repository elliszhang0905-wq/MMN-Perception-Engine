# beta 1.02｜Policy Intelligence 市场环境变量模块

日期：2026-07-17
状态：MVP 已发布生产，继续按证据门禁扩展
维护：MMN研发团队

## 1. 这次解决什么

本模块不是政策资讯页。其唯一业务链路是：

> 官方政策规则 → 购车资格与成本变化 → 本品/竞品补贴后参考位置 → 可验证营销机会 → 人工Eval → MMN机会地图与决策驾驶舱

地图、趋势和气泡只展示上述计算结果，不能绕过来源、人工审核和Eval门禁。

## 2. 后台架构

领域逻辑集中在 `policy_intelligence.py`，`server.py`只负责数据库初始化、MMN模型网关和HTTP接线。

数据表：

- `policy_sources`：Level 1/2/3来源注册与域名白名单。
- `policy_documents`：原始正文、原始/最终URL、SHA-256、抓取时间、解析状态。
- `policy_records`：结构化规则、金额/比例/封顶、适用条件、能源类型、地区、有效期、逐字引句、审核状态。
- `policy_reviews`：审核人、决定、修改前后JSON和时间。
- `policy_analysis_results`：车型×区域分析结果及最终版本。
- `policy_evaluations`：5个20分维度、总分、评分人、修改记录。
- `policy_fetch_runs`：采集任务成功/失败及失败原因。

工作流：

1. 受控抓取器只接受Level 1/2/3允许域名、公开HTTP(S)、HTML/文本、最大800KB；重定向后再次校验域名与公网地址。
2. 若站点robots规则不允许或无法确认，任务失败并记录原因，不绕过；管理员可用`import-source`导入已人工取得的官方原文。
3. MMN模型只能输出JSON抽取草稿；`sourceQuote`必须逐字存在于原文，否则标记`pending_verification`。`stackGroup/stackMode`缺失同样不能通过审核。
4. Level 1/2且人工`approved`的规则才进入车型计算；Level 3永远不能单独发布政策事实。
5. 政策叠加按`stack_group`和`stack_mode`处理；置换与报废按购车情景互斥，地方实施规则不会与同组国家规则重复计算。审批时会再次校验原文引句、结构化问题、日期和金额边界。
6. 营销机会明确拆分为事实、推断、假设、动作、领先指标、转化指标和停止条件。
7. 只有人工Eval总分不低于80的分析，才通过`list_policy_knowledge_signals`进入MMN机会地图证据包、双模型输入和执行建议。
8. 文档、审核、分析和采集任务均按`org_id/edition`隔离；对象ID不能跨企业空间读取或修改。
9. 未确认消费者资格、目录资格等条件时，系统只给出`maxConditionalBenefit`，不计入`maxVerifiedBenefit`；前端明确标注“满足条件时”。

## 3. API

只读：

- `GET /api/policy-intelligence/dashboard`
- `GET /api/policy-intelligence/policies`

云端默认管理员写入：

- `POST /api/policy-intelligence/fetch`
- `POST /api/policy-intelligence/import-source`
- `POST /api/policy-intelligence/parse`
- `POST /api/policy-intelligence/review`
- `POST /api/policy-intelligence/analyze`
- `POST /api/policy-intelligence/evaluate`

MVP已登记并保留原文链接：

- 国家税务总局政策法规库：[2026—2027新能源汽车车辆购置税减免](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5207352/content.html)
- 北京市政府：[北京市2026年汽车以旧换新补贴实施细则](https://www.beijing.gov.cn/zhengce/zhengcefagui/202602/t20260206_4495482.html)
- 工业和信息化部：[减免车辆购置税的新能源汽车车型目录示例](https://www.miit.gov.cn/zwgk/zcwj/wjfb/gg/art/2026/art_f11332e9ca5448ffabe9386255ee2657.html)

地方扩展按省商务厅、市商务局和地方政府官网建立精确URL清单。中国汽车流通协会、中国汽车工业协会和乘联会只能辅助核验，不作为最终政策依据。

采集清单位于`data/policy_source_urls.json`，手动任务：

```bash
python3 scripts/refresh_policy_intelligence.py
python3 scripts/refresh_policy_intelligence.py --parse-drafts
```

第二条命令只生成待人工审核草稿，不会自动发布。

## 5. 前端与系统关系

- 现有决策驾驶舱导航下新增“政策环境分析”，不移动原模块。
- 管理层版新增第8个“政策环境”视图，可选本品并比较4款车型的政策权益上限与补贴后参考价。
- 完整页面包含重点区域政策强度、12个月趋势、车型气泡、逐条官方规则、Policy Opportunity Map、审核队列和五维Eval。
- 机会地图仅收到Eval达标的`policyEnvironment`证据，不会收到抓取页、未审核草稿或低分建议。

## 7. 当前边界与下一步

- 当前为重点区域MVP，不代表全国所有城市已经完成覆盖；缺失地区必须显示为空或待采集，不能用全国政策复制成地方专项政策。
- 车型价格是MVP分析输入并标记`priceSource/priceAsOf`，尚未接入车型主数据；条件满足后价格是规则测算参考，不是经销商成交价。
- 站点不允许自动抓取时必须走人工原文导入与审核，不能绕过robots或反爬限制。
- 下一阶段应扩展地方官方URL维护、车型目录自动匹配、政策变更diff和到期提醒，并用真实线索验证政策内容是否带来转化改善。
