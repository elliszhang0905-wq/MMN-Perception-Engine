# 上汽奥迪竞品社媒真实采集验证

## 研发信息

- 研发日期：2026-07-12
- 版本：真实数据验证 0.1
- 研发团队：MMN研发团队

## 需求背景

以“上汽奥迪”为本品，以“奔驰、理想、蔚来、问界、小米”为竞品，使用 TikHub 对抖音、小红书、微博执行近30天真实基础采集，并将验证结果接入品牌竞争传播 Demo。

## 问题分析

首次严格过滤只保留少量抖音内容。原始结构检查确认：小红书使用 `timestamp` 表示发布时间，但标准化器未映射；微博使用 RFC 2822 格式的 `created_at`，日期解析器只支持数字时间戳和 ISO 时间。微博另出现一次读取超时，复测成功，属于可重试的瞬时问题。

## 技术方案与功能实现

- `normalize_item` 增加小红书 `timestamp` 发布时间映射。
- `_parse_import_date` 增加 RFC 2822 日期解析。
- MMN端无条件执行相关性与严格滚动时间窗口过滤，拒绝超窗、未来时间和无法验证时间；点赞门槛保持可选。
- 微博 RFC 2822 时间可进入时间线聚合，不再落入“日期未知”。
- 每品牌、每平台采集首批结果，关闭评论与榜单补抓以控制费用。
- Demo替换为真实快照，提供平台样本量、拒绝原因、代表内容和原文链接。
- 页面明确标注本轮为首轮关键词、首批结果，不表达为全平台全量声量。

## 实采结果

- 有效内容：186条。
- 平台分布：抖音16条、小红书61条、微博109条。
- 品牌分布：上汽奥迪20条、奔驰29条、理想31条、蔚来38条、问界34条、小米34条。
- 数据质量：51条超出30天窗口被拒绝，11条发布时间仍不可验证。
- 修复后所有品牌三平台采集均完成，本轮竞品重采集无接口警告。
