# 2026-07-10 beta-1.01 发布门禁 Node 运行时解析修复

## 背景

本机没有全局 `node` 命令时，发布门禁在解析运行时的赋值阶段直接退出，终端没有任何提示，也没有继续执行语法检查与浏览器检查。

## 根因

脚本启用了 `set -e`，而 `command -v node` 的失败状态发生在变量赋值中，早于原有的空值判断，因此友好报错分支无法执行。

## 修复

- 优先使用调用方显式提供的 `NODE_BINARY`，兼容绝对路径与 PATH 中的命令名。
- 未提供时再检查系统 `PATH` 中的 `node`。
- 系统没有全局 Node.js 时，自动检查本机内置运行时路径。
- 显式配置无法解析时直接报错，不静默切换到其他 Node.js 版本。
- 所有候选均不可用时，输出明确错误并退出。

## 验证

- 无全局 `node` 的普通终端可直接执行 `bash scripts/release_gate.sh`。
- 显式传入 `NODE_BINARY=/path/to/node` 或 `NODE_BINARY=node` 的既有调用方式保持可用。
- 语法检查、研发档案检查和浏览器门禁均需通过。
