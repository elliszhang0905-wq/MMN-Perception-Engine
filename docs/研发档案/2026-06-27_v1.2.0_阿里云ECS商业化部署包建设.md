# 阿里云 ECS 商业化部署包建设

## 研发日期

2026-06-27

## 版本号

v1.2.0

## 需求背景

MMN Perception Engine 需要从本地运行形态升级为可迁移、可部署、可备份、可恢复的商业化测试部署形态。当前服务器选型为阿里云 ECS，系统为 Ubuntu 22.04 LTS，需要使用 Docker 和 Docker Compose 管理前端入口、后端应用、数据库和定时任务，并集中管理环境变量。

## 问题分析

本地运行版本存在以下商业化迁移风险：

1. 服务默认绑定本机地址，不适合服务器部署。
2. 部分路径依赖本机环境，不利于迁移。
3. 缺少标准化 Docker 构建文件。
4. 缺少 Compose 服务编排。
5. 缺少服务器初始化、部署、备份和恢复脚本。
6. 缺少面向阿里云 ECS 的安全组、日志、备份、域名备案和 SSL 操作文档。

## 技术方案

1. 将服务绑定地址、端口、公开访问地址、数据目录、数据库路径和桌面桥能力改为环境变量配置。
2. 新增 Dockerfile，构建 MMN 应用镜像。
3. 新增 Docker Compose 编排，包含前端入口、后端应用、数据库和定时任务服务。
4. 新增 Nginx 前端入口配置，统一公网 HTTP 测试访问。
5. 新增服务器初始化、部署、备份、恢复脚本。
6. 新增部署说明文档，覆盖阿里云安全组、公网 IP 测试、日志、备份恢复和后续正式化路径。
7. 更新环境变量模板，集中管理 API Key、模型配置、数据库连接、端口和公网测试地址。
