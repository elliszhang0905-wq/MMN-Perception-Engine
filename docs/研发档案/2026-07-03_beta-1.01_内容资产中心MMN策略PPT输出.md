# beta 1.01 内容资产中心 MMN 策略 PPT 输出

## 更新目标

在左侧导航「内容资产中心」下方新增独立功能入口「MMN策略输出」，把自动抓取后的抖音 / 小红书内容资产、达人蒸馏资产、决策驾驶舱、声量数据中心、垂媒竞争格局、人工学习和 RAG 知识合并为一份可直接进入提案制作的车型策略方案。

## 核心逻辑

1. 选择本品与竞品后，模块读取同一轮内容资产和三大上游看板数据。
2. MMN先生成10页策略方案结构：封面、核心结论、当前问题、认知资产/负债/空位、垂媒竞争、声量情绪、抖音打法、小红书打法、达人脚本、行动节奏与KPI。
3. 策略生成经过MMN主控、MMN质检和本地规则交叉验证，页面外显统一为「MMN多模态策略输出」，不展示底层模型名称。
4. 页面支持复制 Gamma Brief、下载 Markdown PPT素材、下载PPTX。

## 数据来源

- 决策驾驶舱：NSR、IPS、购买意向、购买阻力、优先认知标签。
- 声量数据中心：平台分布、标签分布、情绪结构、声量性质。
- 垂媒竞争格局：本品与竞品正反向排名、周期关系、竞争状态。
- 内容资产中心：抖音 / 小红书自动抓取内容、分类、互动表现、车型归因。
- 达人蒸馏：达人能力标签、策略资产、脚本资产、适配场景。
- 人工学习与RAG：人工结论、历史策略知识、车型判断资产。

## 交付边界

- 当前版本已在产品内生成 Gamma-ready brief 和 PPTX 文件。
- 真正的一键在线调用 Gamma 生成云端演示稿，需要把 Gamma 授权/API接入产品运行环境；本次已完成数据层、策略层和交付brief层。
- 所有外显策略文本必须隐藏底层模型名称，只出现MMN口径。

## 验收要点

- 左侧导航中「内容资产中心」下方能看到独立入口「MMN策略输出」。
- 内容资产中心只保留抓取、分类和看板；策略输出不再混在内容资产页面内。
- 点击生成后输出10页策略方案，不展示数据缺口。
- 输出文本是专业咨询腔，但能被市场、销售和达人团队直接理解。
- Gamma Brief、PPT素材、PPTX均可从同一策略方案导出。
