# beta 1.03｜品牌穿透三路品牌与逐竞品结论

## 研发日期

2026-07-23

## 版本号

`beta-1.03-20260723-cockpit-social-brand-1`

## 目标与业务价值

品牌穿透中心不能只列事件和内容证据，还需要在同一客户项目边界内回答两类决策问题：每个品牌当前形成了什么传播结论，以及本品分别面对每个竞品时的认知重叠、竞争压力、缺口和下一步动作。结论必须来自同一冻结证据上的三路独立复核，不能把平台热度、传播关联或任一路意见直接写成市场渗透、购买意愿或销售因果。

## 范围与非目标

本次范围包括旧品牌快照和公开社媒证据 V2 品牌 Mart 的结论适配、三路独立审阅、逐项确定性融合、快照持久化、页面展示、状态/失败语义、证据下钻和桌面/移动端适配。现有导航、事件时间线、证据列表和 194 条历史唯一内容保持不变。

本次不修改热度、情感、风险或销量算法；不重采或覆盖历史证据；不把两路意见降格发布为三路结论；不打开公开社媒证据 V2 的生产开关，也不启动独立 Worker。

## 工程契约

- `build_evidence_packet` 以已验证的唯一内容构建品牌、竞品、证据 ID 和因果边界，按规范 JSON 生成 64 位 SHA-256 指纹。三路首轮输入完全相同，彼此不可见。
- 每一路必须覆盖当前项目全部品牌和全部竞品对照；输出只能引用本证据包中的 ID。逐竞品结论必须同时引用本品与该竞品证据。
- 品牌结论的判断、传播意图和动作方向，以及逐竞品结论的关系、压力和动作方向，必须三路完全一致；共同证据交集不能为空，最低置信度不得低于 0.6。
- 校验和融合按品牌、按竞品对照分别执行。单项结构失败只拦截该项；整路失败导致所有依赖该路的项目 `degraded`，不得用剩余两路补齐。
- 首轮输出不可解析时，只允许在同一冻结证据上自动重试一次；不修补残缺 JSON，不读取其他路答案。长结构字段要求精炼，减少截断风险。
- 客户返回体和页面只显示“MMN交叉验证”“独立复核 A/B/C”等中性标签，不暴露底层模型、供应商、原始错误或技术指纹。指纹只在服务端契约中保留。
- 旧 `brandResults` 的跨品牌重复记录不能成为新事实源；适配必须以快照根级 194 条唯一记录为权威，再按已有品牌字段分组。

## 功能实现

- 品牌穿透中心在事件列表之前增加“每个品牌的传播结论”和“本品分别对应每个竞品”两层决策区。
- 品牌卡显示三路一致结论、传播主题、建议动作、观察/结果指标、共同证据数和最低置信度；未达门槛时只显示分歧或失败原因，不显示推测性建议。
- 逐竞品卡显示双方认知重叠、压力、本品缺口与动作；点击卡片会选中对应竞品并定位事件与证据列表。
- 旧快照首次读取只展示历史已验证事件，并明确提示本轮三路结论待生成；“开始分析”复用 194 条证据，不触发外部重采。
- 新结论和冻结指纹随新快照保存；刷新页面后恢复相同的 6 张品牌卡、5 张逐竞品卡和各项状态。
- 品牌中心保留最多 5 个竞品；快照筛选和保存增加 `centerType=brand_penetration`，避免被社媒趋势默认 3 竞品规则截断。

## 验收结果

- 正常链路：独立 `18765` 端口从品牌穿透中心点击“开始分析”，复用数据库 194 条唯一证据，生成 6 张品牌卡和 5 张逐竞品卡；上汽奥迪品牌项达到“三路一致”，上汽奥迪 × 奔驰达到“高压力”共同判断。
- 分歧与失败：品牌枚举违规、越界证据、对照缺失、非法 JSON 和通道超时均被拦截；本轮其余项按真实结果显示“复核未完成”或“待人工复核”，没有伪造全绿结论。
- 边界：历史分组中的 2 条跨品牌重复没有扩大证据总量，页面和返回体持续为 194 条唯一记录。
- 恢复与持久化：浏览器刷新后恢复 6/5 卡片、状态、194 条证据和 64 位指纹；没有沿用旧项目结果。
- 交互：点击“上汽奥迪 × 奔驰”卡片后品牌筛选切到奔驰，显示 4 个奔驰事件并定位到“奔驰 · 新车上市”证据链。
- 桌面：1440px 真实页面无控制台或脚本错误，结论区与现有项目配置、筛选和事件证据层级共存。
- 移动端：390px 主页面内嵌视口为 364px，品牌卡和逐竞品卡均为单列，`scrollWidth` 不超过 `innerWidth`，无横向页面溢出。
- 客户脱敏：持久化 `brandDecision` 返回体未匹配任何底层模型或供应商名称。
- 回归：新增与相关模块 102 项测试通过；状态包测试和 `check:mmn-state` 通过；完整发布门禁中的 161 项 Python/Node 测试通过。

## 数据保护与运行边界

真实写路径执行前已逐文件备份 `commercial_demo.db` 和 `social_evidence.sqlite`，备份与源文件 SHA-256 一致。验收只新增品牌分析快照，没有覆盖或删除历史内容、备份、用户文档或其他未跟踪文件。默认 `8765` 当时由另一发布工作区占用，本次没有停止或替换该进程；所有实现验收在本工作区独立 `18765` 完成。

## 残余风险与后续

- 三路长结构仍受外部服务时延与格式稳定性影响；当前通过单次自动恢复和逐项失败隔离保持 fail-closed，未达门槛项需要后续人工复核或再次分析。
- 三路长结构的失败关闭会使个别项目显示复核未完成或待人工复核；生产不得把该状态改写为确定结论。
- 发布状态、生产数据库一致性和 1440px/390px 复验以同日中型系统迭代交接档案为准。
