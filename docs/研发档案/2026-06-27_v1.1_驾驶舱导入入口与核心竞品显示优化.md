# 驾驶舱导入入口与核心竞品显示优化

## 研发日期

2026-06-27

## 版本号

v1.1

## 需求背景

决策驾驶舱作为系统首页，需要保持清晰、专业、低干扰的操作界面。原有数据导入区域同时展示多种文件格式入口，界面显得繁杂，不符合成熟业务工具的使用习惯。同时，核心竞品字段在部分车型缺少底层数据时仍显示历史竞品或不相关车型，影响驾驶舱判断可信度。

本次研发目标为：精简驾驶舱数据入口，并建立更严格的核心竞品显示规则。

## 问题分析

1. 驾驶舱导入区存在“导入 Excel”“导入 CSV”“下载 CSV 模板”“查看数据表”等多个按钮，用户需要理解文件格式差异，增加了操作负担。
2. 首页说明文案出现文件格式名称，产品表达偏工程化，不利于业务用户理解。
3. 核心竞品字段直接读取项目配置中的竞品值，可能受到旧项目、演示数据或手动配置残留影响。
4. 当当前车型没有底层排名数据时，系统仍可能展示不相关竞品，造成错误业务判断。
5. 对已有底层排名数据的车型，核心竞品缺少明确取数口径。

## 技术方案

1. 将决策驾驶舱首屏导入区收敛为两个按钮：“导入数据”和“查看数据表”。
2. 保留底层数据导入能力，但不在驾驶舱首屏暴露文件格式差异。
3. 将首页说明文案从“导入声量 Excel”调整为“导入声量数据”。
4. 新增核心竞品计算逻辑：仅从当前车型的懂车帝正向排名数据中取最新周期排名前三的车型。
5. 当前车型无懂车帝正向排名数据时，核心竞品字段显示为空。
6. 在页面渲染时同步校正旧配置中的竞品残留，避免历史状态影响当前显示。
7. 更新前端资源版本号，确保浏览器加载最新页面资源。

## 功能实现

1. 决策驾驶舱数据导入工作台仅保留“导入数据”和“查看数据表”。
2. 声量数据中心保留更完整的数据维护入口，便于高级数据管理。
3. 核心竞品字段改为按当前车型实时计算，不再直接展示项目配置中的旧竞品值。
4. 有数据车型：显示当前车型在懂车帝最新周期正向排名前三的竞品车型。
5. 无数据车型：核心竞品为空，避免误导用户。
6. 切换车型时同步更新本品品牌、车型项目名称和核心竞品列表。

## 修改模块

- 决策驾驶舱数据导入工作台
- 驾驶舱核心竞品显示逻辑
- 车型切换逻辑
- 前端资源版本管理
- 研发档案管理目录

## 测试结果

已完成以下测试：

1. 前端脚本语法检查通过。
2. 首页资源版本号已更新。
3. 驾驶舱首屏导入区按钮数量已收敛为两个。
4. 未匹配到底层懂车帝正向排名数据的车型，核心竞品显示为空。
5. 已匹配到底层懂车帝正向排名数据的车型，核心竞品按最新周期正向排名前三展示。

## 版本变更说明

本次变更属于 v1.0 基线后的交互和数据口径修复版本，版本号记为 v1.1。该版本不改变既有数据导入接口，不删除原有数据能力，仅优化首页入口表达和核心竞品展示口径。

## 后续计划

1. 将更多驾驶舱字段统一改为“有底层数据才显示，无数据不猜测”的口径。
2. 建立数据来源优先级规则，区分懂车帝、汽车之家、声量数据和手动项目配置。
3. 在数据表中增加“当前字段来源”提示，提升可追溯性。
4. 持续完善研发档案，使每次版本演进都有正式记录。
