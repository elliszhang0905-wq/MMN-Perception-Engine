# 达人蒸馏策略资产与脚本资产

## 研发日期

2026-07-02

## 版本号

beta 1.01 持续更新

## 需求背景

达人蒸馏的业务目的明确拆成两类：

1. 策略资产：辅助 MMN 输出车型传播策略、达人推荐、brief、证据链和风险边界。
2. 脚本资产：辅助 MCN 在签约新达人后，快速输出短视频脚本、小红书图文结构、选题和内容模板。

因此达人蒸馏模块不能只显示“样本拆解 / 能力画像 / RAG chunk”，还必须直接沉淀可调用的策略资产和脚本资产。

## 问题分析

原有达人蒸馏模块已经能够提取样本、能力画像和 RAG 知识片段，但资产出口偏知识库，没有明确区分：

- 给 MMN 策略引擎调用的资产。
- 给 MCN 内容生产调用的资产。

这会导致蒸馏结果虽然被保存，但实际业务使用链路不够直接。

## 技术方案

1. 后端从达人画像和样本中实时生成 `strategy_assets` 和 `script_assets`。
2. 不新增数据库表，先保持兼容旧数据；旧样本也能在 payload 层自动生成两类资产。
3. 两类资产进入 `knowledgeItems`，可被 RAG、打法知识库、内容资产中心和决策驾驶舱调用。
4. 平台达人库中的蒸馏达人同步携带 `strategyAssets` 和 `scriptAssets`。
5. 前端达人蒸馏页面新增两块资产展示区，分别展示策略资产和脚本资产。

## 功能实现

- 新增策略资产：
  - 车型传播策略辅助
  - 达人投放与 brief 生成

- 新增脚本资产：
  - 短视频脚本骨架
  - 小红书图文 / 笔记结构

- 达人库卡片显示：
  - 策略资产数量
  - 脚本资产数量

- RAG 知识片段新增：
  - `达人策略资产`
  - `达人脚本资产`
