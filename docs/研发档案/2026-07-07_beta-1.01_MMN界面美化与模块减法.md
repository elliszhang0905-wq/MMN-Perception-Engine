# MMN 界面美化与模块减法研发记录

## 研发日期

2026-07-07

## 版本号

v1.0-beta.1.01

## 需求背景

MMN 当前已经具备声量数据、认知诊断、竞品格局、内容资产、策略输出、RAG 知识库、人工结论学习、空间权限和项目配置等多个业务模块。随着功能逐步增加，默认导航和驾驶舱首屏信息密度偏高，用户进入系统后容易被模块数量分散注意力。

本次优化目标是在不删除既有能力的前提下，对 UI 进行更清晰的视觉整理，并对业务入口做适当减法，让默认路径回到「导入数据、看诊断、看证据、出策略」的主流程。

## 问题分析

1. 侧边栏原先平铺展示全部模块，核心工作流和管理类、资产沉淀类模块权重接近。
2. 决策驾驶舱首屏缺少明确流程提示，用户需要自行理解模块之间的先后关系。
3. 车型判断沉淀面板在首屏权重偏高，容易抢占核心诊断和证据区域的注意力。
4. 页面标题存在部分后台管理口径，不利于形成简洁的 MMN 产品体验。

## 技术方案

1. 将侧边栏改为主流程入口和折叠式二级分组，保留功能但降低非核心模块的默认视觉权重。
2. 在决策驾驶舱增加四步流程提示，明确导入、诊断、证据和策略输出的使用顺序。
3. 将车型判断沉淀面板下移并改为紧凑样式，作为资产沉淀能力而非首屏主任务。
4. 统一页面标题和导航文案，减少管理后台感，强化品牌营销策略场景。
5. 调整卡片、留白、边框、阴影和响应式布局，使桌面和移动端都保持清爽可扫读。

## 功能实现

- 侧边栏改为「主流程」「诊断下钻」「资产沉淀」「系统设置」四组。
- 主流程保留决策驾驶舱、策略输出、RAG 策略台和内容资产四个高频入口。
- 决策驾驶舱新增「导入数据 / 看诊断 / 看证据 / 出策略」流程条。
- 驾驶舱 KPI 与诊断面板前置，车型判断沉淀面板降级到页面底部。
- 页面标题统一改短，例如「声量数据」「认知诊断」「竞品格局」「行动预算」「项目权重」。
- 补充移动端和窄屏下的导航、流程条和 KPI 栅格适配。

## 版本变更说明

本版本属于 UI 美化和信息架构收敛，不删除既有业务功能，不改变数据结构和接口。核心变化是将 MMN 默认体验从模块平铺调整为主流程优先展示，次级模块通过折叠分组继续保留。

## 后续计划

1. 继续梳理低频模块是否需要进入「高级功能」或「项目设置」层级。
2. 为策略输出、内容资产和 RAG 策略台补充更统一的页面视觉规范。
3. 在真实业务数据导入后继续观察首屏信息密度，并按品牌市场团队的日常使用路径继续减法。
