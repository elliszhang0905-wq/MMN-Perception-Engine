# beta 1.03 安全与请求边界零漂移发布

## 发布目标

在不改变现有业务数据、看板信息、指标口径和正常交互的前提下，修复内部调度鉴权、文件请求边界、认证密钥后备、代理来源识别、云端登录写入和服务端错误回显问题。

## 版本

- 版本码：`beta-1.03-20260724-security-boundary-2`
- 工作分支：`codex/security-zero-drift-20260724`
- 数据迁移：无
- 看板字段、指标、排名、周期和结论变更：无

## 实现

1. 内部调度任务使用独立 `MMN_SCHEDULER_SECRET`、Unix时间戳和HMAC-SHA256签名；服务端采用恒定时间比较并限制五分钟时钟偏差。
2. 旧 `Host: mmn-app` 与 `X-MMN-Scheduler: 1` 不再具有任何内部身份含义。
3. 周度集团刷新、月度销量预警刷新、创始人档案周任务和博主能力导入扫描使用同一签名契约。
4. 原始文件入口在读取前统一检查分块传输、`Content-Length`、30MB上限和读取超时。
5. 云端认证密钥缺失时失败关闭；不再把模型服务密钥用作会话签名密钥。
6. 来源IP头只接受来自 `MMN_TRUSTED_PROXY_CIDRS` 的连接；生产按实际容器网段配置。
7. 已初始化的云端账号登录只解析既有组织和用户，不再新建组织、用户、工作空间，不再补种政策或认领历史垂媒数据。
8. HTTP 500未知异常在云端返回中性中文提示，不再暴露内部异常文本。
9. `sharp` 升级到 `0.35.3`，清除依赖审计中的高危图像处理漏洞。
10. 普通看板浏览不再补写车型资产或政策分析；相同产品评价数据不再无意义刷新时间戳。
