# MMN Perception Engine 研发记录

## 研发日期
2026-06-27

## 版本号
v1.3.0

## 需求背景
「创始人蒸馏」模块需要沉淀中国新势力及重点车企创始人、高管的公开表达风格，并形成可用于发布会、社媒、短视频口播、内部汇报和舆论回应的话术资产。实际使用中发现，部分媒体首页、导航页和车型筛选页被误识别为高管公开表达，导致归档内容不具备蒸馏价值。

## 问题分析
原有抓取逻辑对公开网页采用宽松匹配，只要页面包含品牌或人物关键词，就截取附近文本生成归档。汽车媒体首页通常包含大量品牌、车型、导航、报价、排行榜等词汇，容易被误判为有效公开表达，进而污染高管表达素材库。

## 技术方案
1. 建立高管公开表达有效性门槛。
2. 要求素材必须包含明确人物姓名与发言语境。
3. 对导航、车型筛选、报价、排行榜等噪音词设置拦截规则。
4. 后端入库前校验，前端展示前再次过滤。
5. 清理已入库的媒体首页类脏数据。

## 功能实现
- 新增公开表达文本规范化逻辑。
- 新增高管表达有效性判断规则。
- 抓取候选只允许人物级公开表达进入归档，不再使用品牌级模糊匹配。
- 无有效素材时不再写入媒体首页类内容。
- 前端筛选器、归档列表和人物画像均基于有效素材生成。
- 清理本地数据库中由媒体首页误入库的历史记录。

## 版本变更说明
本版本修复了「创始人蒸馏」模块的素材污染问题，提升了高管公开表达归档的可信度和可追溯性。

## 后续计划
1. 增加具体公开文章、发布会、采访、直播文字稿和社媒公开链接导入能力。
2. 建立高管表达素材人工复核入口。
3. 对有效素材进行语言风格、叙事框架和舆论风险的二次质检。
4. 将高管 IP 话术输出纳入 MMN 策略流程模板。
