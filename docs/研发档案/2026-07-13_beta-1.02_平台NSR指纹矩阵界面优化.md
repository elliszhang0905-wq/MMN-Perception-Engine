# 平台 NSR 指纹矩阵界面优化

## 研发日期

2026-07-13

## 版本号

beta 1.02

## 需求背景

产品评价汇总模式原先通过单个平台下拉框与横向条形图展示车型整体 NSR。该方式需要反复切换平台，难以同时识别同一车型在不同内容平台上的认知差异。需求目标是在保持决策驾驶舱信息架构不变的前提下，将该局部模块调整为车型与平台交叉矩阵。

## 问题分析

原界面一次只能观察一个平台，车型横向对比清晰，但平台纵向差异不可见。现有导入结构已经保存全网、垂媒车主口碑及各内容平台的整体 NSR，无需修改导入解析或后端接口。主要风险是平台列较多时产生横向溢出，以及缺失数据被误解为低分。

## 技术方案

沿用 `state.summaryPlatformNsr` 和 `platformNsrSources`，在前端将车型与平台一次性映射为矩阵。按 NSR 数值区间提供高位、中位、低位、负向四档色阶；空值统一显示“样本不足”并使用中性灰色。矩阵容器支持窄屏横向滚动，桌面端按现有内容宽度完整展示。

## 功能实现

- 将“车型整体平台 NSR 对比”调整为“平台 NSR 指纹矩阵”。
- 同屏展示全网、垂媒车主口碑、抖音、小红书、微博、B站和视频号等实际存在的平台列。
- 突出当前本品车型，保留点击任一色块查看全平台 NSR 详情的交互。
- 根据当前本品数据动态生成平台机会提示，不写死车型或平台结论。
- 缺失值显示“样本不足”，不参与数值色阶判断。

## 修改模块

- `app.js`：矩阵数据映射、动态洞察文案与交互结构。
- `style.css`：矩阵布局、色阶、响应式滚动与焦点状态。
- `tests/test_data_first_cockpit_ui.js`：平台矩阵前端契约回归测试。

## 测试结果

- 前端契约测试按 TDD 流程先失败、实现后通过。
- `app.js` Node 语法检查通过。
- `server.py` Python 编译检查通过。
- 使用 `AUDI E7X等5车产品评价_0710_v2.xlsx` 在本地真实浏览器重新导入并验收；七个平台列、五台车型、负向值与样本不足状态均正确呈现。
- 1440 像素桌面视口下矩阵容器 `clientWidth` 与 `scrollWidth` 一致，无非预期横向溢出。
- 点击矩阵色块可打开详情，Esc 可关闭；浏览器控制台无错误。

## 版本变更说明

本次为局部界面优化，不调整导航、路由、导入协议、后端接口或属性 NSR 四象限。原平台选择器由全平台矩阵替代，数据口径保持不变。
