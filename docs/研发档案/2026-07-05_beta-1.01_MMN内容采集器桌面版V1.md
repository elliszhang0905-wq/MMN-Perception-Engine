# MMN内容采集器桌面版 V1

## 研发日期

2026-07-05

## 版本号

beta-1.01

## 需求背景

内容能力蒸馏库已经具备程序内公开页采集、文件导入、内容清洗、标签沉淀和 RAG 能力片段生成能力。为了让用户在日常工作中更方便地采集公开内容、导入授权文件并沉淀达人内容资产，本次新增独立 Mac 桌面采集器。

## 问题分析

原有采集入口嵌入在 MMN 主系统页面中，适合集中管理，但在用户需要频繁处理外部账号链接、授权导出文件和采集任务记录时，桌面独立工具可以提供更直接的工作台体验。该能力需要保持与 MMN 主系统的数据链路一致，同时不能突破平台访问权限和合规边界。

## 技术方案

本次采用独立桌面程序方案：

- 新增 `mmn-desktop-collector` 项目目录。
- 使用桌面应用框架构建 Mac 应用。
- 桌面程序通过本机 MMN API 与主系统联动。
- 公开链接采集调用主系统已有合规采集接口。
- 授权文件导入调用主系统内容能力导入接口。
- 本地保留采集与导入任务记录。
- 提供 Mac DMG 打包配置和打包产物。

## 功能实现

本次实现以下功能：

- 独立桌面程序界面。
- MMN 主系统连接状态检查。
- 输入达人账号、平台和公开主页或作品链接。
- 调用 MMN 内置公开页采集并进入内容能力蒸馏链路。
- 支持 CSV、Excel、JSON、TXT、Markdown 授权文件导入。
- 显示采集、导入、失败和成功记录。
- 一键打开 MMN 主系统。
- 生成 Mac arm64 DMG 安装包。

## 修改模块

- 新增 MMN 桌面采集器项目目录。
- 新增桌面程序主进程、预加载脚本、前端页面、交互逻辑和样式。
- 新增桌面程序 README。
- 新增打包配置。

## 测试结果

已完成以下测试：

- 桌面程序主进程脚本语法检查通过。
- 桌面程序预加载脚本语法检查通过。
- 桌面程序前端脚本语法检查通过。
- 依赖安装完成。

注意事项：

- 当前 DMG 未进行 Apple Developer ID 签名，首次打开可能需要在 macOS 安全设置中手动允许。
- 桌面程序需要 MMN 主系统在本机或指定服务器地址可访问。

## 版本变更说明

本次为新增独立桌面工具，不改变 MMN 主系统页面功能、不改变数据库结构、不影响服务器部署版本。
