# 内容能力内置采集器 V1

## 研发日期

2026-07-05

## 版本号

beta-1.01

## 需求背景

内容能力蒸馏库已经具备账号样本蒸馏、文件导入和 RAG 能力片段沉淀能力，但用户在使用达人账号蒸馏时仍需要先依赖外部工具导出样本。为提升日常使用效率，本次新增程序内置的公开页面采集入口，使用户可以在 MMN 内直接输入账号与公开主页或作品链接，完成公开可见内容读取、结构化蒸馏和知识库沉淀。

该模块的产品目标明确为三类业务用途：

- 做全新达人账号时，通过对标账号蒸馏脚本结构、表达节奏、观点密度和内容方法，用于生成风格相近但不复刻原文的 MMN 原创脚本。
- 做咨询业务时，通过选题标签、技术标签、场景标签和表达风格标签，快速找到适合客户课题的风格博主。
- 持续补齐 MMN 达人库资产，把每次采集、导入和蒸馏结果沉淀为可检索、可调用、可复用的内容能力资产。

## 问题分析

原流程依赖三类样本来源：已入库内容、历史蒸馏样本和本地导出文件。当目标账号尚未被导入时，系统只能提示用户先使用外部工具采集，导致使用链路中断。该问题影响内容能力蒸馏库的完整闭环体验。

同时，抖音、小红书、B站等平台存在登录、验证码、风控和权限边界，系统不能通过绕过方式获取内容。因此，内置采集必须采用合规可控策略：只读取公开可访问页面，遇到访问限制立即停止，并提示用户改用人工补全文本或授权导出文件。

## 技术方案

本次采用最小闭环方案：

- 前端在内容能力蒸馏库中新增公开主页或作品链接输入框。
- 后端新增公开页面采集接口，仅支持 `http/https` 公开链接。
- 采集前检查 robots 权限，无法确认或不允许时立即停止。
- 访问过程中遇到 HTTP 401、403、429、验证码、登录、付费或风控提示时立即停止，不尝试绕过。
- 成功读取公开可见文本后，复用现有内容能力蒸馏链路，写入内容能力来源表和 RAG 能力片段表。
- 未能读取正文时返回人工补全文本状态，不生成虚假内容。

## 功能实现

本次实现以下功能：

- 新增“公开主页/作品链接”输入框。
- “MMN开始蒸馏”按钮在有链接时优先执行内置公开页采集。
- 无链接时保持原本的本地样本和历史蒸馏检索逻辑。
- 前端新增三类业务用途说明：对标账号脚本生成、咨询业务风格检索、达人库资产进化。
- 蒸馏结果卡片改为按照脚本生成、咨询检索、达人资产三个出口呈现。
- 新增采集状态文案，明确告知用户系统只读取公开可见内容。
- 后端新增公开页面标题、描述、正文可见文本提取逻辑。
- 成功采集后自动进入内容能力蒸馏库并生成可调用能力片段。
- 失败时返回清晰原因，包括权限无法确认、登录验证、验证码、风控、可见文本不足等。

## 测试结果

已完成以下测试：

- `server.py` 语法检查通过。
- `app.js` 脚本语法检查通过。
- 本次修改文件格式检查通过。

未覆盖风险：

- 不同平台公开页面结构可能变化，采集结果需以页面实际公开可见内容为准。
- 如平台要求登录、验证码或风控验证，系统会停止自动采集并提示人工补全文本。
