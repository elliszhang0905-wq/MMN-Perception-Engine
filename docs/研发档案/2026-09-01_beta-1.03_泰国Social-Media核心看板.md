# beta 1.03 泰国 Social Media 核心看板

## 发布工单

- 发布版本：`beta-1.03-20260901-thailand-social-dashboard-2`
- 发布范围：MMN出海版决策驾驶舱、泰国社媒静态证据合同、平台覆盖交互、静态资源白名单、测试与发布记录。
- 非目标：不发布其他未提交周榜、社媒V2、数据库、备份或实验文件；不修改Sales Credo与MMN Essence。
- 数据写入：看板数据以版本化JSON只读加载；不迁移、不覆盖生产业务数据库。

## 产品与数据合同

1. 主排序只使用同口径月度用户渗透率，广告可触达率作为独立可切换指标。
2. 用户可同时使用多个平台，平台覆盖率不得相加为100%。
3. 缺失广告触达保持`null`，客户界面显示“未公开”，不用0或其他平台数据代填。
4. 平台策略角色属于有边界的策略推论，不作为预算分配或销售因果结论。
5. 国内版不显示该看板；出海版展示来源类别、样本期、交叉区间和证据边界。

## 工程边界

- 新增独立数据文件、脚本和样式，避免把泰国市场数据写死进主应用逻辑。
- 服务端静态白名单只放行三个新增公开资源，继续拒绝数据库、备份、日志和内部文件。
- 客户界面使用中性能力与证据标签，不暴露模型、插件、数据服务或技术供应商名称。
- 数据合同加载失败时失败关闭，展示“证据暂不可用”而不是伪造数值。

## 发布门禁

- 完整JavaScript与Python套件、状态包、隔离服务和全表面浏览器门禁。
- 泰国看板月度/广告指标切换、平台分层、未公开值、1440px/390px布局和国内版隐藏。
- 新增CSS、JS和JSON均需从正式服务返回200及正确MIME。
- 发布前后生产数据库按表、主键和字段逻辑比较，`quick_check=ok`，不以物理文件哈希代替零漂移证明。
- ECS归档SHA-256、源码/环境/持久数据备份、容器健康、正式代理业务流和日志必须在收口前完成。
