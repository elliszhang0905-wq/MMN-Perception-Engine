# MMN Perception Engine 研发记录

## 研发日期
2026-06-28

## 版本号
v1.0-beta

## 需求背景
MMN Perception Engine 需要从汽车垂直博主、工程师和专业车评人的公开内容中沉淀专业判断能力，形成可复用的垂直专业输出 Skill。第一阶段以“冷静的饺子”作为底盘工程方向样本源，建立底盘工程蒸馏能力。

## 问题分析
原有系统具备声量数据、RAG知识库、高管蒸馏和内容资产能力，但缺少面向垂直专业博主内容的通用导入、结构化拆解、能力画像生成和RAG chunk沉淀机制。导入规则不能绑定特定外部工具名称，进入系统后应统一沉淀为 MMN 数据资产。

## 技术方案
新增“博主能力蒸馏 Skill”模块，采用通用文件解析与本地结构化规则：

- 支持 Excel、CSV、JSON、TXT、Markdown 导入。
- 通用识别标题、作者、链接、发布时间、正文、平台等字段。
- 对底盘工程内容识别滤震、支撑、侧倾、转向手感、车身收敛、后桥跟随、制动姿态、NVH、轮胎匹配等标签。
- 每条样本生成内容拆解、判断链、营销表达、风险表达和RAG chunk。
- 建立博主能力画像，沉淀评价框架、术语体系、判断规则、Agent instruction、短视频模板和客户报告模板。

## 功能实现
本次实现内容：

- 新增左侧功能模块“博主能力蒸馏 Skill”。
- 新增样本数据导入入口。
- 新增公开链接记录入口。
- 新增本地导入目录扫描入口。
- 新增冷静的饺子样本库展示。
- 新增底盘工程标签体系和能力画像展示。
- 新增底盘工程 RAG chunk 展示，并接入现有 MMN RAG 检索池。
- 新增每周日 23:00 本地导入目录扫描任务。
