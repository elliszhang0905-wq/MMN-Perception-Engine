# 试用账号模型分析权限优化

## 研发日期

2026-06-27

## 版本号

v1.2.7

## 需求背景

MMN 云端演示环境需要区分管理员和试用者权限。试用者不应具备导入、清空、同步、写入等管理权限，但应能体验核心策略分析和模型分析能力，便于客户理解系统价值。

## 问题分析

试用者账号已经具备查看演示和运行策略的权限，但部分模型分析接口仍被后端管理权限拦截，导致达人库中的“MMN分析标签”等体验入口无法正常使用。

## 技术方案

1. 保持试用者账号对数据管理能力的限制。
2. 放开试用者账号对核心模型分析接口的访问。
3. 将达人标签分析、策略气泡和 RAG 策略能力纳入试用权限范围。
4. 后端继续拦截导入、清空、同步、写入资产类接口。

## 功能实现

1. 更新云端权限白名单。
2. 允许试用者调用 MMN 分析标签接口。
3. 允许试用者调用 MMN 策略分析接口。
4. 保持管理类接口仅管理员可用。

## 修改模块

- 云端权限控制
- 试用账号权限白名单
- 研发档案

## 测试结果

待云端发布后验证：

1. 试用账号可登录。
2. 试用账号可使用 MMN 分析标签。
3. 试用账号不可导入、清空、同步或写入管理数据。
4. 管理员账号保持完整权限。
