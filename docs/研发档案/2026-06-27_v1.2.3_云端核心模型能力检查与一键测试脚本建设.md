# 云端核心模型能力检查与一键测试脚本建设

## 研发日期

2026-06-27

## 版本号

v1.2.3

## 需求背景

MMN Perception Engine 已完成阿里云 ECS 部署。为了确认云端环境不是仅部署页面外壳，而是已经具备策略模型、知识库、数据库、模型调用和前端展示等完整运行能力，需要建立一份云端能力检查报告，并提供一键测试脚本用于后续发布后的快速验收。

## 问题分析

云端部署完成后，可能存在以下风险：

1. 代码已部署但不是最新版本。
2. 页面可访问但模型配置未进入运行环境。
3. 数据库存在但缺少业务数据。
4. 知识库资料存在但无法被解析或召回。
5. 策略接口可访问但没有真实调用模型。
6. 结果可返回但没有写入数据库。
7. 前端页面可访问但后端能力未连通。
8. 服务器目录未纳入标准版本发布链路。

因此需要通过接口、数据库、模型调用和页面访问进行交叉验证。

## 技术方案

1. 新增云端模型能力检查报告，逐项标注完成状态、证据和风险。
2. 新增一键测试脚本，通过公网地址调用云端接口。
3. 测试脚本覆盖健康接口、前端首页、模型状态、知识库解析、快速策略、深度策略、双模型融合、车型身份识别写入和车型判断写入。
4. 对数据库关键表执行记录数检查，确认业务数据已经进入云端运行库。
5. 测试结果输出为 JSON 文件，便于后续发布验收留档。

## 功能实现

1. 新增 `cloud_model_check.md`。
2. 新增 `test_mmn_cloud.sh`。
3. 测试脚本支持通过 `MMN_CLOUD_URL` 指定云端地址。
4. 测试脚本支持通过 `MMN_CLOUD_SSH_CHECK=false` 关闭服务器数据库计数检查。
5. 测试脚本执行结果写入 `cloud_model_test_result.json`。
6. 更新 `.gitignore`，避免测试结果文件进入版本库。
