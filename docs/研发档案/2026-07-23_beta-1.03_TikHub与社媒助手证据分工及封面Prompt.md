## 目标与边界

TikHub 负责 API 结构化公开证据采集，社媒助手负责用户触发的文件或 RPA 补充；MMN 负责证据准入、任务 Mart、三旗舰分析、确定性融合和人工复核。客户侧不出现插件、服务商或模型名称。

本次不修改第三方插件、不向插件下发 MMN 凭据、不绕过登录/验证码/风控，也不把传播量、互动或热度推断成需求、购买意愿或销量。

## 实现

1. `CanonicalContent` 改为按组织、版本、平台和平台内容 ID 形成稳定标识。
2. 新增 `content_observations`，逐次记录内部来源、采集方式、观察时间、来源指纹和原始归档关联。
3. 新增 `/api/social-evidence/imports`，接收 1 至 500 条受控公开记录，通过同一准入、采样与 Mart 链路落库。
4. 新增封面 Prompt 合同：从同一逐视频证据包冻结可见事实和 OCR，三路独立分析后确定性融合；三路未齐、证据不足或关键字段无多数一致时不发布统一 Prompt。
5. 原始三路输出写入私有运行表，客户界面只显示 `MMN独立分析 1/2/3` 和一个统一结果。
6. 逐视频 UI 的用户手动“生成洞察”同时请求封面 Prompt；后台任务或每日采集不自动触发模型费用。

## 数据与迁移

- 新表：`content_observations`、`douyin_cover_prompt_runs`。
- 既有 `canonical_contents`、业务 SQLite 和原始导入文件不做批量改写。
- 旧 Canonical ID 不在本轮自动重算；新观察从新稳定规则开始写入，避免高风险离线迁移。
- 社媒助手导入原始包经敏感字段清洗后独立归档；客户 Mart 不包含内部来源字段。
