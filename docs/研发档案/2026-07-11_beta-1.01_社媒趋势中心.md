# beta 1.01｜社媒趋势中心

## 变更边界

- 仅新增“核心工作流 → 决策驾驶舱 → 社媒趋势中心”。决策驾驶舱仍可点击进入原页面。
- 新增独立页面、独立后端聚合模块、两个接口和 SQLite 历史快照表；不替换现有页面、业务逻辑或视觉体系。

## 数据口径

- 关键词：车型名；平台：抖音、小红书、微博；单次每平台默认一页、20 条，服务端上限三页。
- 去重：平台内容 ID 优先；缺失时使用平台与规范化文本哈希。
- 文本清洗：解析微博等来源中的 HTML 实体和标签，移除 URL 及属性技术词，再进入热词和情绪分析。
- 热度：`log10(1+点赞+2×评论+3×分享+2.5×收藏+0.08×播放)×20`，单内容封顶 100；跨平台总热度为内容热度求和。
- 正负向：规则证据先行，冲突或无命中标记中性；配置齐全时由 MMN 双模型对相同证据交叉复核。
- 置信度：按有效内容量计算；样本不足时明确展示“未形成高热度”，不补造排行榜。
- 证据：保存来源链接、平台内容 ID、采集时间与 SHA-256 内容哈希。

## TikHub 与安全

- `TIKHUB_API_KEY` 仅由后端环境变量读取，前端接口和页面不返回密钥。
- 搜索端点由 `TIKHUB_SOCIAL_DOUYIN_ENDPOINT`、`TIKHUB_SOCIAL_XIAOHONGSHU_ENDPOINT`、`TIKHUB_SOCIAL_WEIBO_ENDPOINT` 配置，便于版本升级。
- 使用 Bearer 鉴权、三次瞬时错误重试和有界分页；单平台失败会记录 warning，不污染其他平台证据。

## 存储与接口

- `POST /api/social-trends/collect`：采集、归一化、评分、Evidence QA、双模型复核并保存快照。
- `GET /api/social-trends/latest?keyword=...&edition=...`：读取当前组织与版本下的最新快照。
- `social_trend_snapshots`：按组织、国内/出海版本、车型关键词隔离历史结果。

## 验证

- 新增 4 项单元测试：规范化/热度/情绪/矩阵、去重与置信度、快照隔离、密钥仅后端读取。
- 发布门禁新增导航层级与独立看板端到端检查，验证排行榜、置信度、证据链接及双模型策略输出状态。
- 无真实 `TIKHUB_API_KEY` 时接口明确返回配置错误；不得把模拟数据标记为真实数据验收。
- 部署验证中修正达人 Worker 继承应用 HTTP 健康检查造成的假异常，改为 Celery 定向 ping；不改变达人蒸馏业务逻辑。
- 真实 TikHub 验收发现 Cloudflare 拒绝 Python urllib 默认签名；社媒趋势与达人适配器统一增加固定 MMN User-Agent，不包含密钥或用户数据。
- 三平台真实采集通过后，将 Evidence QA 调用修正为 MMN 网关统一的标准 messages 数组，避免字符串请求被模型供应商拒绝。

- 车型关键词：智己 L6；抖音 16 条、小红书 20 条、微博 16 条，共 52 条。
- 三个平台均返回 HTTP 200，warning 为 0，置信度为 1.0，证据链接和内容哈希完整。
- 真实采集快照：`6b0be0c2db4327f581a218c7`；复核快照：`006d1ab0841fa6ca0b626f24`。
- DeepSeek Evidence QA 已成功；Qwen/百炼现有凭据被供应商拒绝，系统按规范保留 `manual_required`，待恢复 Qwen 权限后重跑同一快照即可，不需重复消耗 TikHub 采集额度。

## TikHub 能力补足（2026-07-11）

- 搜索采集从单页关键词扩展为按 1/7/30/90 天窗口、有界双页采集，并对本品与最多 3 台竞品分别归一化、去重和计算热度。
- 接入抖音与微博实时热榜、抖音/小红书/微博热门内容评论；评论结果独立计算正向、负向与中性，不与正文口径混算。
- 新增平台热度份额、创作者热度排行、品牌/媒体矩阵识别、主题聚类、风险议题、发布时间序列、历史快照环比和车型综合热度排行。

- 修复 TikHub 客户端只读取进程环境导致后端 `.env` 中既有密钥无法生效的问题；密钥仍仅在服务端读取，不进入 HTML、JavaScript、接口响应或日志。

## 车型联动与指标释义补齐（2026-07-11 23:10）

- 结果顶部新增“本次分析车型”标签组：本品固定选择并作为 Benchmark，最多 3 台竞品可独立显示或隐藏。
- 车型标签联动本品 × 竞品对比卡和原始证据下钻；隐藏某竞品时，其比较卡和证据同步隐藏，再次点击恢复。
- 每台车型比较卡新增抖音、小红书、微博分平台热度分，明确原“三平台热度份额”仅为本品口径。
- “证据一致的正向内容”更名为“竞品正向内容热度”，明确数值为判定正向内容的综合热度之和，单位为热度分，不是百分比、销量或市场份额。
- Benchmark 明确定义为：以本品为固定基准，在相同时间窗、相同平台集合和相同热度公式下比较。
- 热度走势改为可聚焦和悬停的交互柱，气泡显示日期、热度分和内容量。
- 平台实时热榜改为逐条 Top 5，不再拼接成一段文本。
- 浏览器门禁新增车型标签联动检查；资源版本提升为 `beta-1.01-social-dashboard-4`。
