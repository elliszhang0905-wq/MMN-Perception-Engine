# 品牌车型归属规则污染修复

## 研发日期

2026-06-27

## 版本号

v1.2.8

## 需求背景

MMN 汽车营销引擎的车型资产库需要严格区分品牌与车型，并保证品牌下只展示该品牌真实车型。车型资产归属错误会直接影响决策驾驶舱、声量数据中心、内容资产中心和策略分析结果。

## 问题分析

车型资产识别规则中存在过度泛化匹配，使用了单独车型后缀作为品牌归属依据，导致不同品牌中包含相同后缀的车型被误归类。例如含有 L6 字样的车型可能被误归入智己品牌。

## 技术方案

1. 移除单独后缀识别品牌的泛化规则。
2. 增加完整品牌车型组合识别规则。
3. 明确乐道 L60、银河 L6、智己 L6/LS 系列等车型归属。
4. 前端标准化逻辑优先覆盖历史缓存中的错误归属。
5. 后端入库逻辑同步采用相同标准化规则。
6. 发布门禁增加品牌车型归属专项检查。

## 功能实现

1. 删除 L6、LS 等泛词归属规则。
2. 新增乐道、吉利银河、智己车型标准化规则。
3. 新增后端车型身份标准化规则。
4. 新增发布门禁专项：智己车型库不得混入乐道 L60 和银河 L6。

## 修改模块

- 前端车型标准化规则
- 后端车型身份入库规则
- 发布门禁脚本
- 研发档案

## 测试结果

已完成：

1. 本地语法检查通过。
2. 发布门禁检查通过。
3. 智己车型库专项检查通过。
4. 乐道 L60 已归属乐道。
5. 银河 L6 已归属吉利银河。
6. 智己车型库仅保留智己品牌车型。
