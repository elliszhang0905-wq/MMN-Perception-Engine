# beta 1.03 社媒趋势竞品召回与全部证据修复

## 工单目标

修复社媒趋势中心中竞品相关内容召回不足、竞品证据默认展示不全、采集状态过度承诺的问题。保持现有公开数据源、时间窗、平台范围、热度公式和三路审阅规则不变，不新增独立业务模块。

## 问题事实

- 旧结果中“奔驰GLC EV”只使用少量字面表达，未覆盖公开内容中常见的“奔驰纯电GLC”“全新奔驰纯电GLC”“GLC纯电”等车型表达。
- 车型采集原始返回51条、去重后37条，只有2条进入相关池；35条因车型表达未命中被排除，其中包含多条明确的纯电GLC内容。
- 页面“原始内容下钻”读取热门证据池，而不是无热度门槛的全部相关池，因此用户看不到已经入池但未达到热门门槛的竞品证据。
- “已采尽”只能证明当前查询计划停止翻页，不能证明平台全库已穷尽。

## 修复合同

1. 车型召回必须保留可追溯的命中表达和匹配方法。
2. 经过复核的车型表达可标记为覆盖已核验；自动生成但未复核的表达只能标记为部分覆盖，不能冒充完整。
3. 车型卡分别显示抓取候选、去重后、有效入池、未入池、重复内容和热门内容。
4. 内容量、情感、风险和原始内容下钻使用全部相关池；热门门槛只影响热门排行榜和热门筛选。
5. 页面默认显示本品与已选竞品的全部相关证据，并保留全部相关、热门内容、风险内容以及本品、竞品筛选。
6. 查询停止后只显示“查询已完成”；存在别名覆盖不足、平台失败或其他真实缺口时显示“部分采集”及原因。
7. 缺失、冲突、超时和降级不得转换为看似完整的业务结论。

## 实现结果

- 为奔驰GLC EV增加经过复核的车型表达集合，并增加车型与能源语义的确定性匹配。
- 每条入池内容保存相关性匹配方法与命中表达，便于后续审计。
- 每车型采集结果增加表达覆盖状态与热门准入诊断。
- 前端车型卡增加六项抓取漏斗；“数据完整性”调整为“查询状态”。
- 原始内容下钻默认读取全部相关池，新增全部相关、热门内容和风险内容三种证据池筛选。
- 删除社媒趋势中的“已采尽”表述，统一为“查询已完成”或“部分采集”。
