# 2026-07-02 beta 1.01 MMN多层语义识别模块

## 更新目标

将原先偏“正负面情绪判断”的文本识别能力升级为汽车营销多层语义标签体系。单条用户原文、视频标题、弹幕、评论或图文正文进入 MMN 后，需要同时输出可用于策略、脚本和达人蒸馏资产的结构化标签。

## 标签体系

本次建立 `mmn-semantic-v1`，至少覆盖 8 类标签：

- 车型：识别品牌、车型、标准化车型名和原文命中表达。
- 产品属性：底盘、智驾、空间、舒适、补能、价格、质量、安全、外观、服务等产品关注点。
- 情绪倾向：认可、质疑、观望、焦虑、失望、期待等细分情绪。
- 购买阻塞点：价格门槛、信任不足、质量担忧、补能焦虑、维修成本、交付周期、保值率、政策不确定等。
- 竞品关系：对比、替代、压制、被压制、同级参照等关系。
- 身份表达：家庭用户、年轻用户、增换购、商务、性能偏好、理性决策、女性用户等身份线索。
- 场景需求：家庭、通勤、长途、高速、雨雪、露营、商务、城市、补能等场景。
- 策略动作：澄清、第三方实测、场景化传播、价格权益、试驾转化、KOL/KOC种草、售后承诺、竞品对标等动作建议。

## 产品入口

在“内容资产中心”加入 `MMN语义识别` 工作台：

- 用户粘贴单条文本后点击“识别语义标签”。
- 页面展示 8 类标签卡片，每类标签都可以人工修改。
- 点击“保存人工校准”后，将预测结果、人工修正结果和备注写入本地数据库，形成后续优化样本。

## 后端接口

- `POST /api/semantic/analyze`
  - 入参：`edition`、`text`
  - 出参：`result`、`schema`
  - 逻辑：先使用本地规则引擎稳定兜底；如已配置 MMN/Qwen 能力，则再让模型在固定 schema 内增强输出。
- `POST /api/semantic/calibrate`
  - 入参：`edition`、`sourceText`、`predicted`、`corrected`、`userNote`
  - 出参：校准样本 `id` 和 `createdAt`
  - 逻辑：写入 `semantic_calibrations` 表，保留原始预测与人工校准差异。

## 风险控制

- 识别结果必须是结构化 JSON，不允许只返回自然语言结论。
- 模型输出失败时，本地规则引擎仍能返回基础标签，页面不空白。
- 人工校准入口常驻，避免模型一次性误判后无法纠正。
- 车型识别接入已有标准车型身份能力，避免把同一车型不同写法直接当成多台车。
