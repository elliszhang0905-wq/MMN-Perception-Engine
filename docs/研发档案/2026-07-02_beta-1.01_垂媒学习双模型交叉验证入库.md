# beta 1.01 更新记录：垂媒学习双模型交叉验证入库

## 更新范围
- 页面：垂媒竞争格局
- 模块：MMN智能体学习
- 版本：beta 1.01
- 日期：2026-07-02

## 更新内容
1. `MMN学习正反向` 改为双模型交叉验证链路。
   - Qwen：生成正反向竞争格局主判断。
   - DeepSeek：复核事实边界、过度承诺和策略风险。
   - MMN融合：输出最终外显策略卡。

2. RAG入库内容改为MMN融合后的结果。
   - 不再把单一模型原文直接沉淀为知识。
   - Qwen、DeepSeek、本地规则记录只作为交叉验证过程保留。

3. 页面外显交叉验证状态。
   - 结果卡片展示“交叉验证完成”，不外显底层模型品牌。
   - 折叠区使用“MMN主控执行记录 / MMN策略质检记录 / MMN本地规则记录”，不把底层模型名称作为用户侧表达。

## 验收标准
- 点击“MMN学习正反向”后，接口内部返回双模型过程与本地规则过程。
- 页面主体显示MMN融合结果，不显示单一模型原始回复。
- 写入RAG知识库的 `knowledgeItem.body` 与外显融合结果一致。
- 页面外显文案不出现 Qwen、DeepSeek 等底层模型品牌。
