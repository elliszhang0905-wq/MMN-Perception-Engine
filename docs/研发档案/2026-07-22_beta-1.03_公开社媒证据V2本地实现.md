# beta 1.03｜公开社媒证据 V2 本地实现

## 研发日期

2026-07-22

## 版本号

`social-evidence-v2-local-1`

## 需求背景

旧社媒趋势与品牌穿透链路以单关键词抓取、统一热度聚合和共享快照为主，无法稳定回答 MMN 真正需要的“变化、用户语言、竞品占位、品牌关联、来源角色、证据覆盖和缺口”。本次目标是把外部公开数据服务降为可替换采集基础设施，并为两个中心建立不同的业务证据集。

## 问题分析

- 查询计划缺少别名、竞品、主题、场景、议题、事件、排除词、时间窗、采样和预算的统一版本契约。
- 旧任务主要依赖进程内状态，难以承受服务重启、独立 Worker 和失败续跑。
- 原始响应、规范内容与面向页面的结果混在同一链路，两个中心容易共享不相干字段。
- 跨平台互动指标直接相加会制造虚假的统一市场量级；公开传播证据也不能证明需求、购买意愿或成交因果。
- 旧移动端侧栏在 390px 下占据大段首屏，真实业务内容难以使用。

## 技术方案

- 新增版本化 `social-evidence-query-v2`，按组织、版本、项目和中心冻结查询范围。
- 新增独立 SQLite 与原始响应目录，分别保存 QueryPlan、持久化 Job、脱敏 RawRequest、CanonicalContent、Job-Content 关联和 Evidence Mart。
- 新增独立 Worker 入口，使用原子领取和单写者模式；支持线程模式做本地证明、外部进程模式做部署、关闭模式 fail-closed。
- Compose 中新增默认不启动的 `social-evidence-v2` profile，只有显式选择该 profile 才运行独立 Worker。
- 增加请求缓存、平台均衡上限、来源角色配额、任务预算、企业日预算、时间窗/链接/排除词硬准入和重启恢复。
- 社媒趋势使用 `social-trend-mart-v2`；品牌传播穿透使用 `brand-penetration-mart-v2`，禁止复用旧页面快照契约。
- 通过功能开关、影子模式和旧链保留实现可回滚迁移。

## 功能实现

- 社媒趋势中心显示查询计划、时间窗、平台覆盖、缺失平台、变化基线、用户原话、原生指标字段和原文链接。
- 品牌传播穿透中心显示品牌关联、竞品同批证据提及、来源角色、代表证据与明确因果边界。
- API 新增 capabilities、QueryPlan preview、持久化 jobs、显式 retry 与 latest marts；客户侧不暴露底层数据服务商名称和原始错误。
- 390px 下压缩全局导航，并为两个中心保留无横向页面溢出的可用视口。

## 测试结果

- V2 契约、缓存、预算、租户隔离、恢复、独立 Worker、API、影子模式和 UI 静态契约测试通过。
- 既有社媒趋势、社媒任务、双模型门禁和品牌穿透回归测试通过。
- 隔离端口 18767、独立临时数据库完成 1440px 与 390px 浏览器真实页面验证；桌面时间窗/平台计数与移动端 `scrollWidth=innerWidth=390` 已核对。
- 浏览器证据保存在本机验收产物目录；使用的是可识别的隔离验收样本，不代表外部数据源已在本机实时采集成功。

## 版本变更说明

V2 默认关闭，旧 `/api/social-trends/*` 链路不删除。`MMN_SOCIAL_EVIDENCE_SHADOW_MODE=true` 时后端可运行但前端仍保持旧链；关闭 `MMN_SOCIAL_EVIDENCE_V2_ENABLED` 可立即回滚。此次没有 GitHub 推送、ECS 部署、生产数据库迁移或生产密钥变更。
