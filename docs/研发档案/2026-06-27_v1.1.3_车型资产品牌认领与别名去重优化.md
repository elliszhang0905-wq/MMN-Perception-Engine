# 车型资产品牌认领与别名去重优化

## 研发日期

2026-06-27

## 版本号

v1.1.3

## 需求背景

MMN 汽车营销引擎需要长期沉淀品牌、车型和竞品关系资产。车型资产库中如果存在“待确认品牌”未认领、同一车型中英文别名重复、品牌名与车型名混淆等问题，会直接影响决策驾驶舱、声量数据中心、垂媒竞争格局、内容资产中心和车型判断工作台的专业可信度。

本次研发目标为：强化车型资产的品牌归属、别名归一和去重机制，提升汽车行业数据资产质量。

## 问题分析

现有车型资产库存在以下风险：

1. 部分车型可能被归入“待确认品牌”，无法进入正确品牌层级。
2. 同一车型可能因中英文别名差异形成重复资产，例如“极氪009”“ZEEKR 009”“Zeekr 009”“Zeeker 009”。
3. 品牌名和车型名可能混淆，例如将“阿维塔06”整体识别为品牌。
4. 前端车型分组和后端车型入库规则未完全统一，可能出现展示层已修正、数据层仍重复的问题。
5. 发布检查中缺少车型资产标准化专项验证。

## 技术方案

1. 增加本地车型标准化规则，对高频品牌和车型别名进行确定性归一。
2. 将 Zeekr、ZEEKR、Zeeker、极氪统一认领为“极氪”品牌。
3. 将“极氪009 / Zeekr 009 / ZEEKR 009 / Zeeker 009”统一为同一 canonicalKey。
4. 对“阿维塔06”“沃尔沃EX90”等品牌加车型命名方式进行强规则识别。
5. 前端品牌分组使用标准化 canonicalKey 去重，避免同一车型重复显示。
6. 后端车型身份入库时覆盖不规范模型返回，确保数据层也按 MMN 车型资产规则保存。
7. 将车型资产标准化检查加入发布门禁。

## 功能实现

1. 新增前端本地车型标准化函数，用于品牌认领、车型标准化和 canonicalKey 生成。
2. 新增后端本地车型标准化函数，用于车型资产入库前清洗。
3. 优化车型分组逻辑，按标准化车型资产去重。
4. 优化模型身份识别提示，明确 Zeekr / ZEEKR / Zeeker / 极氪的统一规则。
5. 发布门禁新增车型资产检查项：
   - 阿维塔06 必须归属阿维塔。
   - 沃尔沃EX90 必须归属沃尔沃。
   - 极氪009、Zeekr 009、ZEEKR 009、Zeeker 009 必须合并为一个车型资产。
   - 不得生成“待确认品牌”分组。

## 修改模块

- 车型资产标准化规则
- 前端品牌车型分组逻辑
- 后端车型身份入库逻辑
- 车型身份识别提示
- 发布门禁脚本
- 研发档案

## 测试结果

已完成以下测试：

1. 前端脚本语法检查通过。
2. 后端脚本语法检查通过。
3. 发布门禁新增车型资产检查项。
4. 极氪009、Zeekr 009、ZEEKR 009、Zeeker 009 可合并为同一车型资产。
5. 阿维塔06 可归属至阿维塔品牌。
6. 沃尔沃EX90 可归属至沃尔沃品牌。

## 版本变更说明

本次版本记为 v1.1.3，属于车型资产库质量优化版本。该版本不改变原始数据导入接口，不删除既有数据，但会在展示层和入库层使用更严格的品牌归属与车型别名归一规则。

## 后续计划

1. 持续扩充品牌与车型别名库。
2. 增加车型能源版本区分规则，避免纯电、增程、插混和燃油版本被误合并。
3. 将更多高频品牌纳入车型资产专项检查。
4. 对历史车型资产执行一次清洗迁移，减少既有重复记录。
