# 本地主数据库与服务器镜像同步机制

## 研发日期

2026-06-27

## 版本号

v1.2.1

## 需求背景

MMN Perception Engine 已完成阿里云 ECS 测试部署，但当前阶段业务使用仍以本地 Mac 为主。为了保证本地日常操作数据与服务器测试环境数据保持一致，需要建立一套本地优先、服务器镜像、可回滚、可追溯的数据同步机制。

## 问题分析

本地运行环境与服务器运行环境存在数据隔离：

1. 本地 `data/` 目录中保存了完整业务资产、导入数据和项目快照。
2. 服务器 Docker volume 中仅保存服务器端运行数据。
3. 两端访问地址不同，浏览器临时状态不会天然共享。
4. 如果直接覆盖服务器数据，可能丢失服务器端新增记录。
5. 如果直接以服务器为主，可能覆盖本地主工作环境中的关键数据。

因此当前阶段需要采用本地优先的双向合并策略，先将服务器新增内容回流到本地，再将本地合并后的完整数据镜像到服务器。

## 技术方案

1. 新增本地优先同步脚本，默认连接当前 ECS 测试服务器。
2. 同步前分别对本地和服务器数据进行备份。
3. 从服务器容器 `/app/data/` 拉取数据包。
4. 对 SQLite 数据库执行表级合并：
   - 服务器新增表补充到本地。
   - 服务器新增记录插入本地。
   - 同主键冲突时保留本地记录。
5. 对数据文件执行补齐合并：
   - 服务器存在、本地不存在的文件回流到本地。
   - 本地已有文件不被服务器覆盖。
6. 将本地合并后的 `data/` 推送到服务器 Docker volume。
7. 重启服务器应用服务和定时任务服务。

## 功能实现

1. 新增 `scripts/sync-local-primary.sh`。
2. 新增根目录快捷入口 `sync-local-primary.sh`。
3. 更新 `README_DEPLOY.md`，增加本地与服务器数据同步说明。
4. 同步脚本支持通过环境变量覆盖 ECS 地址、用户、密钥、远程目录、数据目录和数据库文件名。
5. 同步脚本执行完成后输出同步策略和执行结果。
