# 2026-07-08 beta 1.01 MMN PPT Agent工作流

## 研发日期

2026-07-08

## 版本号

beta 1.01

## 需求背景

MMN需要把策略报告输出升级为可编辑、可复用、可校验的商业咨询型PPTX生成流水线，而不是图片型PPT或单一插件安装能力。该能力服务于品牌传播、内容策略、竞品传播分析、达人Brief和策略报告输出，不进入经销商门店销售场景。

## 问题分析

原有策略PPT能力更偏结果下载和轻量导出，缺少稳定的页面结构JSON、生成源码留存、资料解析入口、预览图和自动校验规则。后续若直接生成图片型页面，会削弱客户二次编辑和复用能力，也不利于形成MMN长期报告资产。

## 技术方案

- 以 PptxGenJS 作为可编辑 `.pptx` 主生成引擎。
- 以 MarkItDown 作为 Word、PPT、PDF、Excel 等资料解析工具。
- 以 python-pptx 作为 PPTX 读取、解析和轻量编辑辅助。
- 以 Marp CLI 作为结构版演示稿生成工具。
- 以 Mermaid CLI 作为流程图、逻辑图生成工具。
- 以页面结构 JSON 作为页面意图、版式元素、目录、页码和校验规则的中间协议。

## 功能实现

- 新增 `skills/mmn-consulting-pptx/SKILL.md`，沉淀MMN专用PPT Agent工作规范。
- 新增 `src/ppt-agent/`，包含PptxGenJS生成、预览导出和校验逻辑。
- 新增 `scripts/mmn_ppt_ingest_sources.py` 和 `scripts/mmn_ppt_inspect.py`，分别用于资料解析和PPTX读取检查。
- 新增 `scripts/run_mmn_ppt_agent.sh`，统一运行生成、预览、校验、Marp、Mermaid和PPTX检查。
- 新增 `examples/ppt-agent/input/` 示例结构、Marp草稿和Mermaid逻辑图。
- 扩展 `package.json`，加入 `ppt:generate`、`ppt:preview`、`ppt:validate`、`ppt:marp`、`ppt:mermaid`、`ppt:build` 命令。

## 测试结果

- 已在本地运行完整PPT Agent工作流。
- 生成可编辑PPTX、页面结构JSON、生成源码副本、预览图、校验报告、Marp结构稿和Mermaid逻辑图。
- 自动校验覆盖中文溢出、元素重叠、标题层级、图表可读性、品牌配色、页码、目录一致性和PPTX页数一致性。

## 版本变更说明

本次为新增独立报告输出基础设施，不替换现有MMN主页和既有策略流程。后续可把现有策略报告接口逐步接入该页面结构JSON协议。
