# MMN Eval 可视化页面

## 研发日期

2026-07-17

## 版本号

beta 1.02 / MMN Eval Dashboard

## 需求背景

MMN Eval v0.1 已具备离线合同、硬门禁、五维评分和版本比较，但成果只能通过命令行报告查看。需要在不重构现有 MMN 信息架构的前提下，加入一个可直接查看结果、运行评测并完成人工复核的页面。

## 技术方案

- 保留 `index.html + app.js + style.css + server.py` 现有单页架构。
- 在「系统设置」增加 `Eval评测`，不改变其他导航、模块名称和视觉变量。
- 新增 `mmn_eval/dashboard.py`，负责读取真实报告、运行种子集、组织隔离和人工复核记录。
- 在现有认证层中增加三个薄 API：报告读取、运行 Eval、保存人工复核。
- 页面不构造 baseline 或趋势数据；没有真实比较时展示明确空状态。
- 人工判断只处理 `human_review` 案例，不允许绕过硬门禁；驳回必须填写理由。

## 功能实现

- 总览：发布判断、综合平均分、通过、待复核和失败数量。
- 质量维度：证据、推理、可执行性、任务适配和不确定性。
- 案例列表：全部、通过、待复核、失败四种筛选及详情查看。
- 人工闭环：填写判断理由，记录通过或驳回结论，并按组织保存。
- 运行与导出：重新运行内置种子评测，导出当前 JSON 报告。
- 诚实边界：种子结果只用于证明机制，不代表 MMN 真实策略能力；没有真实基线时不显示伪造比较。

## 边界与后续

本次是本地实现，没有同步 GitHub 或 ECS。当前种子集只验证机制；下一步需要从真实历史策略输出中脱敏抽取 20–50 条案例，由 MMN 负责人完成首轮裁决并冻结阈值，之后再扩展 Gold Set、模型 Trace、Langfuse 和正式发布门禁。
