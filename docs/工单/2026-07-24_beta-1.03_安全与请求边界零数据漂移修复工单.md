# beta 1.03 安全与请求边界零数据漂移修复工单

## 1. 工单目标

在不改变现有业务数据、看板口径、看板内容、信息架构和正常用户路径的前提下，修复已确认的鉴权与请求边界问题，并完成本地、GitHub、ECS 和生产真实流程闭环。

## 2. 用户价值

- 阻止外部请求伪装成内部调度任务。
- 阻止超限文件在应用内被整体读入内存。
- 避免云端认证密钥缺失时退回模型密钥或公开演示密钥。
- 限定反向代理来源头的可信范围。
- 让登录保持认证职责，不再顺带补种或认领业务数据。
- 避免未知服务端异常直接暴露内部技术信息。

## 3. 硬约束

1. 发布前后全部现有业务表必须逐表、逐主键、逐字段一致。
2. 不删除、不改写、不重算现有看板数据，不改变车型、周期、排名、指标和结论。
3. 不执行数据库结构迁移。
4. 不启用当前关闭的功能开关，不改变模型路由、提示词、采集源和内容口径。
5. 浏览器验收产生的临时写入必须按明确主键精确清理或恢复。
6. 任一零漂移门禁失败即停止发布并回滚，不得用文件哈希代替逻辑数据对比。

## 4. 实施范围

### 4.1 内部调度鉴权

- 删除以 `Host` 和布尔请求头作为内部身份的判断。
- 调度器使用独立共享密钥、时间戳和 HMAC 签名。
- 服务端校验签名和时间窗口；失败返回 401，不进入刷新逻辑。
- 管理员在看板内手工刷新仍使用原有管理员会话，不改变交互。

### 4.2 原始文件请求边界

- 所有原始文件入口统一拒绝分块请求、无效或负数 `Content-Length`。
- 在读取请求体之前统一执行 30MB 上限和读取超时。
- 现有小于等于上限的文件解析、保存和返回结构保持不变。

### 4.3 认证与代理边界

- 云端要求显式配置 `MMN_AUTH_SECRET`，缺失时失败关闭。
- 不再使用模型 API 密钥作为认证签名密钥。
- 本地免登录开发模式保留兼容后备值。
- `X-Real-IP` 只接受来自配置的可信代理网段；默认只信任回环地址。

### 4.4 登录去业务写入

- 已存在的云端账号登录只解析既有组织和用户作用域、签发会话。
- 登录接口不再补种工作空间、政策数据或认领历史垂媒数据。
- 初始化职责保留在部署初始化流程；若账号尚未初始化，登录失败关闭并给出中性提示。

### 4.5 错误回显

- 保留明确的用户输入、权限和业务校验提示。
- 未知服务端异常对外返回中性中文提示，完整原因只进入服务端日志。
- 不改变成功响应和看板字段。

### 4.6 看板读取零副作用

- 普通浏览仅在浏览器内使用本地车型标准化结果；只有数据导入动作才允许同步车型资产。
- 政策页自动生成策略预览但不保存分析记录；只有用户点击“重新运行三模型复核”才持久化。
- 相同指纹的产品评价数据重复同步时直接返回既有版本，不刷新时间戳。

## 5. 非目标

- 不在本工单内拆分 17,000 行服务文件或重构全部路由。
- 不在本工单内接入 HTTPS、证书或启用 Cookie 会话；这是独立基础设施工单。
- 不更换账号体系、数据库或部署架构。
- 不处理与本工单无关的本地未跟踪数据、备份、日志和截图。

## 6. 工程契约

### 调度签名

- 输入：HTTP 方法、路径、Unix 时间戳。
- 算法：`HMAC-SHA256(MMN_SCHEDULER_SECRET, method + "\n" + path + "\n" + timestamp)`。
- 允许时间偏差：最多 300 秒。
- 比较：恒定时间比较。
- 密钥：不得进入日志、响应、Git 或工单。

### 上传请求

- 默认最大值：`MAX_UPLOAD_BYTES`，当前为 30MB。
- 超限：HTTP 413。
- 分块传输：HTTP 400。
- Content-Type 和原有文件解析规则继续由各业务入口负责。

### 兼容性

- 原有 API 路径、成功响应结构、前端调用方式和看板字段不变。
- 调度器与服务端必须在同一提交内发布。
- 新环境变量同时注入应用和调度器；未配置时云端调度失败关闭。

## 7. 验收标准

### 正常路径

- 管理员登录、19个客户入口和8个管理视图正常。
- 管理员手工刷新看板正常。
- 签名正确的内部周度、月度刷新请求通过鉴权。
- 合法小文件导入保持原结果。

### 边界路径

- 30MB边界值按契约处理；超过1字节即在读取前返回413。
- 无效、负数长度及分块原始请求被拒绝。
- 过期时间戳、错误签名、伪造Host和旧 `X-MMN-Scheduler: 1` 均不能绕过鉴权。
- 非可信连接不能通过伪造 `X-Real-IP` 影响登录限流键。

### 失败与恢复

- 缺少调度密钥时任务失败关闭且不刷新数据。
- 缺少云端认证密钥时不签发会话。
- 未知服务端异常不向客户返回内部路径、SQL、供应商或密钥信息。
- 回滚到上一应用提交后，原环境和数据可直接恢复运行。

### 持久化与零漂移

- 本地验证只使用生产数据副本。
- 生产发布前创建代码、环境和完整持久数据备份。
- 验收前后SQLite `quick_check=ok`。
- 最终全部业务表按主键和字段排序后的逻辑指纹一致，变化表为0。

### 真实流程与端面

- 1440px和390px完成真实管理员登录、首页、集团看板、线索看板和关键管理视图检查。
- 控制台运行时错误、失败请求、HTTP 5xx均为0。
- 页面文案、指标、排名、周期、图表和下钻内容与发布前一致。

### 回归

- 新增安全边界测试在旧代码上失败、修复后通过。
- 全量Python、Node契约和发布门禁通过。
- 依赖审计无新增高危或严重问题。
