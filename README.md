# MMN Perception Engine / MMN汽车营销引擎

Version 1.0 baseline: `v1.0`

MMN汽车营销引擎不是一个简单调用大模型的demo，而是一个多模型驱动的汽车营销策略系统。底层模型供应商可以替换，真正属于MMN的核心资产是汽车营销策略模型、工作流、知识库、输出规范和模型调度逻辑。

## 产品边界

MMN 与 Credo 是两条独立产品线，不应混成一个系统。

- MMN 面向车企品牌、市场部门、车企代理公司和汽车垂直 MCN，聚焦营销策略、达人蒸馏、内容生产、品牌传播与报告输出。
- Credo 面向经销商、销售顾问和门店管理者，聚焦本品卖点、竞品对比、销售攻防表达与到店接待辅助。
- 两者可以共享底层车型知识库、竞品资料和部分数据结构。
- 两者的前端产品、用户权限、功能路径、交付口径、页面信息架构和商业化模型必须独立设计。
- 禁止把对方的业务功能直接塞进本项目。

## 核心定位

MMN把汽车营销判断拆成一套稳定流程：

本品 -> 竞品 -> 用户情绪 -> 产品属性 -> 身份认同 -> 认知空位 -> 传播动作

系统中的Qwen、DeepSeek、OpenAI或未来客户私有模型，都是底层AI发动机。用户侧统一看到的是MMN用户感知引擎、MMN策略模型、MMN多模型引擎和MMN高管蒸馏模型。

## MMN Strategy Model

当前策略模型层包括：

- NSR：口碑健康与正负向结构判断
- Emotion：用户情绪结构与疑虑识别
- Attribute：产品属性、卖点、痛点、竞品标签
- Identity：用户身份、车主/KOC/KOL/潜在人群
- Positioning：车型定位、用户心智锚点、竞品占位判断
- Gap：认知空位、传播缺口、购买阻力
- Action：平台动作、内容动作、预算动作、复盘动作
- RAG知识库：MMN母库、客户私有库、项目学习库
- 周报生成：面向品牌与车型的周期策略输出
- 竞品传播分析：垂媒正反向排名、竞品声量关系、传播机会
- 达人蒸馏：达人DNA资产、内容方法论、达人 brief 和脚本能力
- 内容Brief：把策略判断转成达人、MCN和内容团队可执行的内容任务
- 脚本生产：短视频、图文、发布会、客户报告表达资产
- 品牌/高管IP蒸馏：公开表达归档、语言风格、品牌叙事资产
- 市场周报：面向品牌与车型的周期策略输出
- 策略报告输出：面向品牌市场、代理公司和管理层的策略报告

MMN 当前不承载经销商门店接待、销售顾问即时使用、门店销售攻防等 Credo 场景。

## 多模型调度

用户不需要选择Qwen或DeepSeek。MMN会按分层推理架构自动调度：

- 日常标签识别、内容摘要、达人风格拆解：优先使用 flash/plus 快速模型
- 策略生成：先由一个旗舰模型输出主结论，前台立即返回初版结果
- 策略质检：另一个旗舰模型只作为 critic，在后台异步检查逻辑漏洞、证据不足、竞品误判和策略风险
- 深度复核：用户可在结果页手动触发，不阻塞首屏响应
- 模型不可用或超时：回退到缓存、RAG和MMN本地规则引擎

后台可以继续保留各模型API Key和调用配置，但用户侧不把底层供应商作为核心卖点。

## 数据与知识库

本地版目前主要运行在这台Mac上，数据保存在项目目录和浏览器本地存储中。后续SaaS化时，需要把企业空间、品牌空间、车型项目、知识库和数据版本迁移到多租户数据库。

数据隔离原则：

- 国内版与出海版数据隔离
- 集团、品牌、车型、项目分层
- MMN母知识库、客户私有知识库、项目学习库分层
- 原始数据、清洗数据、策略结论和人工学习分层

## 合规边界

采集程序只处理公开可访问数据、用户手动导入数据或客户合法授权数据。不绕过验证码、登录限制、付费墙、风控、人机验证，不在代码中写死账号、密码、Cookie或Token。
